# 동행길 접근성 자료 조사

조사일: 2026-10-30 (Asia/Seoul). 학교 기준점: 위도 37.5950991, 경도 127.038992. 우선 범위는 학교 주변 약 2km 및 기존 지도 스냅샷 범위다. 원본 자료의 공간 범위는 보고서마다 따로 기록한다.

## 근거 기록 방법

[evidence-fields.json](evidence-fields.json)은 향후 구간별 근거의 공통 필드 정의다. 값이 확인되지 않으면 null로 남긴다. 측정값·시설대장·지도등록값·영상관찰·지형추정을 구분하고, 출처 기준일과 조회일을 각각 기록한다. 이 파일은 데이터 스키마 구현이나 접근성 측정 결과 자체가 아니다.

[field-check-template.csv](field-check-template.csv)는 현장 확인 기록 양식이다. 두 기본 경로에 공통인 OSM way 6개에 대한 18개 질문과 벤치 연결부 질문 1개를 넣었다. 결과는 모두 unknown이며 현장 관측값은 아니다.

## 통합 원칙

1. 공식 데이터의 도로/시설 ID와 OSM ID는 서로 다르므로 별도 대응표를 만든다. 단순 최근접 지점은 연결 후보이며, 길의 좌우·층·교량/지하 구분·출입구를 확인해야 연결이 확정된다.
2. 도로 전체 폭, 보도 폭, 장애물을 제외한 최소 유효폭을 같은 속성으로 저장하지 않는다.
3. 등고선이나 표고에서 계산한 경사는 추정으로 기록한다. 교량/육교/지하보도와 보행면의 종단·횡단 경사를 별도로 확인한다.
4. 설치 자료, 개방 시간, 현재 가동 상태를 각각 관리한다. 엘리베이터가 있어도 지상에서 필요한 층으로 이어지는지는 따로 확인한다.
5. 미등록/미확인 값을 통행 가능으로 바꾸지 않는다. 자료 간 충돌은 원본 근거를 보존한 채 기록한다.
6. 법정 설치 기준을 해당 길의 현장 측정값으로 채우지 않는다.

## 추가 통합 출처 확인

[서울시 자치구별 도보 네트워크 공간정보 OA-21208](https://data.seoul.go.kr/dataList/OA-21208/A/1/datasetView.do)는 WGS84 노드·링크를 통해 횡단보도·육교·버스정류장·지하철 출입구 정보를 제공한다고 설명한다. 공식 설명은 **2020년 기준**이다. 이번 열람 시 포털 갱신일은 2026-10-30, 메타정보 수정일은 2026-02-27이었다. 포털 갱신일을 시설 현장 확인일로 해석하면 안 된다. 공공누리 제1유형을 표시한다. 이번 통합 작업에서는 소개 페이지를 확인했으며 원본 노드·링크 행과 유형코드 파일은 확보하지 않았다.

## 앱 적용 순서

1. 보고서에서 실제 확보한 자료와 메타데이터만 확인한 자료를 분리한다.
2. 공개 원본을 확보하고 좌표계·단위·기준일·재사용 조건을 확인한다.
3. 학교 주변만 추출해 OSM 원본 구간과 대응표를 만들고 표본을 지도에서 확인한다.
4. 현장확인이 필요한 길은 출발점→종월2교의 일반 최단/벤치 경유 경로부터 점검한다.
5. 근거가 충분한 속성부터 경로 엔진에 반영하고 기존 조건 제외/경유 테스트로 확인한다.

이번 작업은 조사와 결과물 작성 범위다. server.mjs 및 경로 엔진의 동작 변경, 배포, 외부 계정 신청은 수행하지 않는다.

## 1차 조사 통합 결과

네 담당의 조사를 완료했다. 새 공식 지형/보도/승강기 공간 원본은 아직 확보하지 못했으며, 공개 설명과 일부 시설 안내를 확인했다. 기존 OSM 원본은 직접 집계했고 원본 ID별 근거를 JSON에 남겼다.

- 기존 엔진 채택 way 4,463개 중 수치 경사는 0%가 등록된 1개다. 나머지 incline 태그는 방향/존재 표현이며 수치 크기가 아니다.
- 기존 거리 우선 약 674m와 벤치 경유 약 958m 경로의 수치 경사는 전체 미확인이다. 두 경로 공통 way 6개를 우선 점검 대상으로 잡았다.
- 원본에는 crossing 태그가 있으나 엔진이 비용/통과 조건으로 활용하지 않는다. 데이터 수집 공백과 프로그램 활용 공백을 분리해야 한다.
- 보도통계의 폭과 안전누리의 도로폭 차이 산출값은 실제 병목 통과폭을 대체하지 못한다.
- 출입구·승강기 설치/가동/임시폐쇄 출처를 조합할 수 있으나 이번에 인근 설비의 현재 가동을 확인한 것은 아니다.

우선 확보 대상은 보도통계 OA-22240, 횡단보도 OA-23081/OA-22906, 경사지형 OA-22241 원본이다. 안전누리의 길단위 수치는 원본 제공 방식과 이용조건 확인이 선행된다. 로그인/신청이 필요한 출처는 이 조사에서 계정을 만들거나 기관에 연락하지 않았다. 상세 출처·제약은 담당 보고서를 따른다.

# 보도·턱·폭 자료 조사

조회일: 2026-10-30 (한국 시간). 대상: 서울사대부중 `(37.5950991, 127.038992)` 주변 약 2km, 기존 OSM 범위 남서 `(37.580,127.020)`~북동 `(37.611,127.058)`.

## 결론과 확보 수준

인터넷에서 확인한 공식 자료 중 **보도 방향·위치·폭·포장**을 제공한다고 명시한 서울시 보도통계와 **횡단보도 위치·식별자·신호등 여부** 자료가 유용하다. 서울안전누리는 도로 폭의 차이로 계산한 보도 폭 레이어도 공개한다. 그러나 이번 조사에서 학교 주변 개별 구간의 **실측 최소 통과폭, 양쪽 턱 높이, 장애물 간격을 확인한 원본 행은 확보하지 못했다**. 소개·메타데이터 확인을 학교 주변 접근성 검증으로 해석하면 안 된다.

이 문서는 실제 열람한 공식 페이지의 메타데이터와 적용 판단이다. XLSX/CSV 원본은 다운로드하지 못했고 새 실측 관측값은 없다. 웹 도구는 동적 다운로드 버튼의 파일 URL을 노출하지 않았으며, 임의로 파일 주소나 API 인증키를 만들지 않았다. 로그인·자료제공 신청·기관 문의는 하지 않았다. 자료 기준일, 파일 수정일, 페이지 갱신일은 서로 구분했다.

## 1. 서울시 보도통계자료 — 폭·방향·포장 후보

- 공식 출처: https://data.seoul.go.kr/dataList/OA-22240/F/1/datasetView.do
- 원본 포털: https://www.data.go.kr/data/15100606/fileData.do
- 파일: `서울시 보도 통계자료_2025.xlsx`, 0.56MB, 파일 수정일/페이지 갱신일 `2026-09-15`, 연간 갱신. 제목상 2025 자료이며 각 행 측정일은 원본 확인 필요.
- 공간범위: 서울시 자치구별 집계와 특별시도 노선별 세부자료. **서울의 모든 골목길을 포괄한다고 볼 수 없다.**
- 공식 설명상 필드: 관리기관별 연장·면적·포장재, 노선별 보도 방향·위치·연장·폭·면적·보도블록 종류·투수 여부·시공연도·횡단구성.
- 이용조건: 공공누리 1유형(출처표시, 상업적 이용·변경 가능).
- 확보상태: 공식 설명·파일 존재 확인. 원본 셀·좌표 유무·학교 주변 노선 수록 여부 미확인. 공공데이터포털 링크는 제목까지 확인했으나 추가 열람은 콘텐츠 유형 오류.
- 연결 제안: 원본 확보 후 월곡로·종암로 등 학교 주변 도로명으로 후보를 찾고 시작/끝 위치와 도로 방향을 대조한다. 도로명만 같은 전체 OSM way에 일괄 덮어쓰지 않는다. `reported_sidewalk_width_m`로 보관하고, 장애물을 제외한 `minimum_clear_width_m`와 구분한다.

## 2. 서울안전누리 보도폭 — 산출값이며 실측 통과폭과 구분

- 공식 출처: https://safecity.seoul.go.kr/distFclt/cfMapDs/cfMapDs.page?menuId=MENU_SSNS_000176
- 확인 위치: 다중운집인파 → 인파영향요인 → 보도폭. 지도 설명에는 서울 전역을 대상으로 한다고 명시.
- 기준자료: 국토지리정보원 연속수치지형도 도로중심선 `2024-07`.
- 산출방법: **전체 도로폭에서 차도폭을 뺀 값**. 지도에는 1~2m, 2~3m 등 등급을 표시하며 1:20,000 이상 확대에서 레이어 표시.
- 확보상태: 공식 레이어 설명과 범례 확인. 학교 주변 피처 원본/속성/API/다운로드/재이용 라이선스는 미확인. 지도 공개가 원본 재배포 허가를 자동으로 의미하지 않는다.
- 적용 판단: `derived_non_carriageway_width_m` 같은 보조 속성으로만 검토한다. 양쪽 보도 합산 여부, 좌우 분리 여부, 가로수·전봇대·점유물 차감 여부를 설명만으로 알 수 없다. 값을 반으로 나누어 양쪽 보도 폭을 만들거나 휠체어 통과 가능 여부를 판정하면 안 된다.

## 3. 서울시 자치구별 도보 네트워크 공간정보 — 연결 구조 보완

- 공식 출처: https://data.seoul.go.kr/dataList/OA-21208/A/1/datasetView.do
- 내용: 노드·링크 기반 보행 도로, 대로변 횡단보도·육교·버스정류장·지하철 출입구. 설명상 **2020년 기준**, WGS84. 페이지는 `2026-10-30` 갱신·매일1회로 표시하지만 이를 전 구간 2026년 현장 갱신으로 해석하지 않는다.
- 코드 파일: `도보네트워크_링크노드유형코드.xlsx`, 파일 수정일 `2024-07-05`. API 이름은 검색 결과에서 `TbTraficWlkNet` 확인. 원본 코드표는 미확보.
- 이용조건: 공공누리 1유형.
- 확보상태: 공식 설명·API/코드표 존재 확인. 공개 샘플 API 열람을 시도했으나 웹 도구에서 URL 해석 실패, 응답 행은 미확보. 인증 없이 정상 응답한다고 확정하지 않는다.
- 적용 판단: 코드표 확인 후 보도·횡단보도·육교 연결을 기존 OSM과 대조한다. 필드 확인 전 폭·턱 데이터가 들어 있다고 가정하지 않는다. 단순 교차 선형은 평면 교차인지 층이 다른지 확인해야 한다.

## 4. 최신 횡단보도·교차로 시설 위치 — 턱 조사 지점 만들기

- 공식 출처: https://data.seoul.go.kr/dataList/OA-23081/F/1/datasetView.do
- 파일: `서울시 교차로 및 횡단보도 시설·위치정보_20260824.xlsx`, 1.69MB. 파일명 기준 `2026-08-24`, 공개/갱신 `2026-09-07`.
- 필드 설명: 자치구, 횡단보도 관리번호, 교차로 관리번호, 종류, 보행신호등 설치 여부, 교차로명, X·Y 좌표. 서울 T-GIS 관리자료.
- 이용조건: 공공누리 1유형.
- 확보상태: 공식 페이지·파일·열 설명 확인, 원본 미확보. X·Y가 어떤 좌표계인지 원본에서 확인해야 한다.
- 별도 자료: https://data.seoul.go.kr/dataList/OA-22906/S/1/datasetView.do — `서울시 자치구 횡단보도 정보.csv` 4.77MB, 파일 수정일 `2026-08-10`, 페이지 공개/갱신 `2026-04-22`. 공식 설명상 관리번호·종류·지번·경위도 제공, 이용허락범위 제한 없음. 역시 원본 미확보.
- 적용 판단: 성북구 및 인접 동대문구의 학교 주변 좌표를 추출하여 OSM 횡단보도와 대조한다. 각 횡단보도의 **양 끝 진입부를 별도 관측점**으로 만들고 턱 높이·경사·폭을 채운다. 신호등이나 횡단보도 존재는 턱낮춤·무단차 확인이 아니다.
- 중복 주의: 과거 자료 OA-22364(2023-05-30 파일)와 함께 사용할 때 관리번호·날짜로 중복을 관리한다. 최신 페이지가 있다고 모든 시설의 최신 현장 확인을 보장하지 않는다.

## 성북구 추가 조사 단서

검색에서 `2025년 관내 보도 실태조사 용역`과 단차·경사·유효폭 조사 계획을 다룬 보도를 발견했다. 다만 **공식 성과품·조사표·완료 보고서·개방 파일은 확인하지 못했다**. 완료 예정일이 지났다는 이유로 완료·공개됐다고 판단하지 않는다.

- 보조 단서(2차 보도, 확인된 구간값에 사용하지 않음): https://www.newsro.kr/article243/753172/ (2025-02-24).
- 추가 확인 경로: 성북구 열린데이터 https://data.sb.go.kr/ 및 성북구 공식 계약/정책연구 자료. 담당기관에 요청한다면 공정별 실측 위치·조사일·유효폭·단차 원본이 대상이며, 이번 조사에서는 요청을 보내지 않았다.

## 앱에 연결할 관측 구조 제안

다음은 연구에 따른 설계 제안이며 앱 구현이나 새 측정값이 아니다.

| 항목 | 관측 단위 | 필요한 기록 |
| --- | --- | --- |
| 보도 존재 | 도로 좌/우 또는 독립 보행선 | 좌우 기준방향, 연결 시작/끝, 차도 분리 여부 |
| 폭 | 보도 구간과 병목점 | 총폭, 장애물 제외 최소폭, 단위 m, 좌표, 측정/산출 구분 |
| 턱 | 횡단보도 양끝·차량 진출입부 | 잔여 높이 m, 턱낮춤 유무, 경사로 방향, 접속 도로 |
| 장애물 | 점/짧은 구간 | 볼라드 간격, 가로수·전주·시설물, 일시적 점유 여부 |
| 노면 | 보도 구간 | 재질, 파손·단차, 관측시점 |

공통 필드: `source_url`, `source_record_id`, `observed_at`, `published_at`, `retrieved_at`, `evidence_type`(official_record/derived/imagery/field), `geometry`, `osm_way_id`, `side`, `matching_status`, `confidence_note`. 값이 없는 항목은 `unknown`/null로 남긴다. 통계 폭, 산출 폭, 실제 최소 통과폭을 하나의 필드로 합치지 않는다.

현장 검증 우선순위는 ① 학교 앞 출발점 및 종월2교 시연 경로의 모든 횡단 진입부 ② 경로가 좁은 보도/차도로 바뀌는 지점 ③ 벤치 진입부 ④ 대체 경로가 없는 병목점이다. 각 지점에서 양쪽 턱, 유효폭, 횡단경사, 볼라드 간격, 차량 진출입, 임시 공사를 함께 기록해야 연속된 통행 가능 경로를 판단할 수 있다.

## 다음 작업

1. 위 두 XLSX와 횡단보도 CSV 원본을 공식 다운로드로 확보하고 실제 열 이름·좌표계·측정일을 검사한다.
2. 학교 주변만 추출해 원본 식별자를 유지한 검토용 GeoJSON을 만든다.
3. 기존 OSM과 자동 근접 매칭한 후보는 `unreviewed`로 남기고 도로 좌우·층·실제 접속을 수동 검토한다.
4. 접근성 판단에 필요한 턱·최소폭이 비어 있으면 실측 또는 날짜가 명확한 관찰로 채운다. 일반 설치기준을 해당 지점의 실측값으로 채우지 않는다.

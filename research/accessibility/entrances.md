# 출입·시설 연결 조사

조회일: 2026-10-30 (한국 시간). 담당 범위: 서울대학교사범대학부설중학교 기준점 `(37.5950991, 127.038992)` 주변 약 2km. 이 좌표는 프로젝트 기준점이며 검증된 교문 좌표가 아니다. 기존 OSM 수집 범위는 `(37.580, 127.020)`~`(37.611, 127.058)`이다.

## 결과와 확보 수준

공식 자료에서 시설의 설치 위치·층 연결, 승강기 가동상태, 출입구 공사 폐쇄, 공공시설 출입 조건을 각각 얻을 수 있는 출처를 확인했다. 이들을 결합해야 도로에서 목적지 내부까지의 접근성을 판단할 수 있다.

이번 조사에서 새로 확보한 것은 **공식 웹페이지의 설명과 일부 시설의 명시적 편의정보**다. 신규 승강기 원본 파일이나 API 응답 행은 내려받지 못했다. 소개 페이지의 갱신일을 개별 설비의 가동 확인 시각으로 사용하지 않는다. 기존 저장소의 2026-02-11 에스컬레이터 설치 원본과 49개 인근 역 추출 행은 로컬에서 재검토했다. 원본을 이번에 새로 수집한 것은 아니다.

## 공공시설: 확인된 속성과 미확인 접근 구간

### 오동숲속도서관

- 정확한 주소: 서울특별시 성북구 화랑로13가길 110-10 (하월곡동). 공식 시설 페이지 식별자: E7의 `cotId=172646e9-64ae-4a93-8aa3-69a1b517158a`, E8의 `3515866`.
- E7에서 자동문, 장애인 주차장, 장애인 화장실을 확인했다. 이를 시설 속성으로 저장할 수 있다. 자동문은 단차 없음·충분한 유효폭을 뜻하지 않는다.
- E7의 안내는 09:00~18:00, 매주 월요일과 일요일을 제외한 법정공휴일 휴무다. 폭우·폭설·태풍 등으로 공원이 폐쇄되면 임시휴관/제한 운영할 수 있다고 안내한다.
- 이는 웹페이지 안내로서 오늘의 실제 개방 확인은 아니다. E8 시간표는 비어 있고, 운영기관 [오동숲속도서관 홈페이지](https://www.sblib.seoul.kr/odlib)는 이번 열람에서 시간 초과로 확인하지 못했다. 앱에 자동 운영시간 판정을 붙이기 전에 운영기관 현행 안내를 우선 확인한다.
- 도서관까지의 자락길 전체 경사·유효폭·입구 단차, 자동문이 어느 입구인지, 휴관 시 외부 회랑·화장실도 닫히는지는 미확인이다. 시설 주소를 도로의 가장 가까운 노드에 붙여서 '휠체어 접근 가능'으로 만들면 안 된다.
- 시설이 기존 라우팅 bbox 안에 들어오는지는 **검증된 좌표가 없어 이번 조사에서 확정하지 않았다**. 주소를 별도 지오코딩하고 기존 수집 범위와 비교해야 한다.

### 서울사대부중·종월2교·벤치·정류장

- 학교는 기존 문서의 월곡로 36 주소와 프로젝트 기준점을 알고 있으나, 학교 공식 홈페이지 `https://www.snu.ms.kr/`는 이번 도구에서 접근되지 않았다. 교문별 일반인 출입 허용시간과 개방 규정은 공식 근거를 확보하지 못했다. 개인 블로그의 운동장 개방 경험은 통행 허용 근거로 채택하지 않았다.
- 종월2교의 양쪽 접속부 단차·폭, 정류장에서 보도 진입부 단차, 벤치의 도로 연결과 착석 공간은 이번 조사에서 공식 측정자료를 확보하지 못했다. 존재 여부와 통행 가능성을 구분해 `unknown`으로 유지한다.
- 보도에서 학교 내부나 사유지로 들어가는 경로를 공공 통과도로로 자동 허용하지 않는다. 학교를 목적지로 삼는 경우에도 확인된 교문 밖 도착점과 교내 도착점을 분리한다.

## 권장 데이터 구조와 결합 절차

이는 구현 권고이며 앱 코드를 변경하지 않았다.

1. `facility_id`, `station_id`, `entrance_id`, `level_from`, `level_to`, `direction`, `access_rule`, `opening_hours`, `operational_status`, `observed_at`, `source_as_of`, `source_url`, `evidence_type`를 분리한다. 위치는 `coordinate_status`와 좌표계를 함께 저장한다.
2. 역명만으로 조인하지 않는다. 역 코드·호선·승강기번호·출입구 번호를 조합하고, '성신여대입구(4)'처럼 노선 구분이 있는 표기를 보존한다. 제공 스키마에서 공통 키를 확인해야 한다.
3. 지상 출입구 노드와 지하 층 노드를 별도로 만든다. 계단·엘리베이터·에스컬레이터는 수직 연결 간선으로 만들고, 에스컬레이터는 확인된 방향만 허용한다.
4. 시설 설치 목록(E1/E6)에 가동정보(E2), 위치·상세(E4), 폐쇄정보(E3)를 결합한다. 가동 응답이 없거나 오래됐으면 `unknown`; 설치기록만으로 `operational=true`를 만들지 않는다.
5. 지상 보도→출입구 사이 연결은 가장 가까운 점 직선이 아니라 실제 통로/횡단보도로 연결한다. 실내외 계단 없는 연속 동선이 확인되기 전 휠체어 경로의 확정 간선으로 넣지 않는다.
6. 도서관 같은 시설은 문·화장실 등의 POI 속성과, 그 시설까지 이어지는 보행 구간 속성을 분리한다. 안내문에 있는 '무장애' 표현으로 인접한 모든 길의 접근성을 채우지 않는다.
7. 출입구 폐쇄 종료일이 지났더라도 정상 개방 근거를 갱신하고, API 실패 때는 마지막 정상 응답의 시각을 표시한다. 상태 수집은 비밀키가 필요한 경우 Node 서버에서 처리한다.

## 남은 온라인 확보 작업

- E1의 실제 파일 내려받기 경로를 확인하고 파일명/헤더 불일치를 해소한 뒤 인근 역 엘리베이터 설치 행 추출.
- E2/E3/E4의 공식 Open API 명세에서 정확한 서비스명·인증 요구·상태코드·개별 장비 ID·좌표 기준을 확인하고 합법적으로 사용 가능한 인증으로 샘플 조회. 이번에는 로그인·키 발급·기관 문의를 실행하지 않았다.
- 주변 역 공식 층별 안내도와 교통약자 이동 동선도를 확보해 지상 출입구와 각 설비 간 연속 연결 확인. 서울교통공사 홈페이지가 시간 초과되어 해당 안내도는 미확보다.
- E5는 변경금지 조건이 있으므로 원본 보관과 가공 재배포를 구분해 검토.
- 시설 운영기관의 공지에서 운영시간·재난통제·공사 상태 갱신. 관광 안내의 수정일과 현장 확인일은 다르다.

## 현장 확인 우선순위

1. 실제 기본 경로 출발점, 종월2교 양 접속부, 경유 벤치의 진입 지점: 단차·통로 폭·가림막·잠금·계단 없는 접속을 확인하고 도로 노드와 사진을 함께 기록.
2. 학교 교문별 개방 조건: 일반인 목적지 도착 가능 여부와 교내 통과 허용을 구분.
3. 사용할 역 출입구→외부 엘리베이터→대합실 동선: 횡단보도, 문턱, 개찰구, 운영시간, 고장 시 대체 동선 확인.
4. 도서관 출입문 위치와 실제 유효폭, 실외 접근로의 경사와 단차, 휴관일 화장실/휴식공간 이용 가능 여부 확인.
5. 관찰 시각·관찰 방향·측정 도구·오차·날씨를 함께 기록하고 날짜가 오래된 사진은 현재 상태로 확정하지 않는다.

## 조사 한계

실제 새 API 응답이나 신규 좌표가 확보되지 않았으므로, 이번 보고서만으로 기존 지도 구간을 접근성 검증 완료로 바꿀 수 없다. 확인된 시설 편의정보와 출처 후보를 기록하는 단계다. 파일 목록/본문의 불일치, 공통 오류 안내창, 운영기관 페이지 접근 실패를 별도로 남겨 후속 확인의 우선순위를 정했다.

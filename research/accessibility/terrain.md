# 경사·지형 조사

조사일: 2026-10-30 (Asia/Seoul). 대상: 서울사대부중 `(37.5950991,127.038992)` 주변 약 2km. 기존 도로 원본 범위는 남서 `(37.580,127.020)`~북동 `(37.611,127.058)`이며, 이 사각형과 반경 2km는 일치하지 않는다.

## 결론

가장 먼저 확보할 자료는 서울시 **OA-22241 표고점·등고선 SHP**다. 공식 파일 목록과 이용조건을 확인했다. 다만 이름이 '경사도'여도 제공기관은 완성된 경사 SHP가 아니라고 명시한다. 서울안전누리에는 별도로 **길단위 세그먼트 경사도** 레이어가 있으며 등고선 기반 파생 결과라고 설명한다. 양쪽 모두 보도면의 실측 종단·횡단 경사라고 해석하면 안 된다.

이번 조사에서 인터넷상의 공식 메타데이터·이용 가이드·품질관리 기준을 열람했다. **학교 주변 DEM/등고선 원본 파일, 구간별 경사 수치, 지도 화면의 특정 지점 측정값은 확보하지 않았다.** 이에 따라 앱의 경사 속성을 추가하거나 어떤 길을 완만하다고 판정하지 않았다.

## 출처와 확보 상태

### T01. 서울시 경사도 — 실제 제공물은 표고점·등고선

- 공식 페이지: https://data.seoul.go.kr/dataList/OA-22241/F/1/datasetView.do
- 대응 공공데이터 메타데이터: https://www.data.go.kr/catalog/15100676/fileData.json
- 열람으로 확인한 사실: 설명은 **2023년 기준 수치지형도에서 경사를 추출할 수 있는 표고점·등고선 SHP** 제공이라고 명시한다. 서울 전역 자료이므로 대상 지역을 공간 필터링할 후보다.
- 파일 목록: `서울시 등고선.zip` 44.78MB, 수정일 2025-03-20; `서울시 경사도.zip` 101.52MB, 수정일 2023-12-26. 파일명만으로 두 ZIP의 레이어 구성과 서로의 차이를 확정하지 않았다.
- 페이지 메타정보 수정일: 2026-02-11. 이는 측량일이 아니다.
- 이용조건: 공공누리 제1유형(출처표시, 상업적 이용 및 변경 가능).
- 확보 수준: 공식 설명·파일 목록·이용조건 열람. ZIP 다운로드, 내부 DBF/PRJ와 높이 필드 검수는 미완료. 따라서 실제 좌표계, 등고간격, 표고점 밀도와 대상 지역 누락 여부는 미확인이다.
- API: 해당 페이지는 파일 제공 방식이다. 경로별 고도를 반환하는 API는 확인하지 못했다.
- 앱 적용: SHP 원본 확보 후 표고점/등고선으로 지형 표면을 만들고 도로 중심선에 보간한 경사를 **추정값**으로 별도 저장한다.

### T02. 서울안전누리 길단위 경사도

- 공식 지도·설명: https://safecity.seoul.go.kr/distFclt/cfMapDs/cfMapDs.page?menuId=MENU_SSNS_000016
- 화면의 인파영향요인 설명: 각 길단위 세그먼트별 경사도이며 원천은 국토지리정보원 연속수치지형도 등고선(2024.03), 공간범위는 서울 전역이다. 레이어는 1:20,000보다 확대된 상태에서 표시된다고 안내한다.
- 범례는 `%` 단위 구간이다. 각도(°)로 대입하면 안 된다.
- 같은 화면의 보도 유효폭은 전체 도로폭에서 차도폭을 뺀 값이며 2024.07 도로중심선 자료에 기반한다고 설명한다. 장애물을 뺀 실측 통행 폭으로 확인된 것은 아니다.
- 확보 수준: 공식 설명과 범례 열람. 학교 주변 세그먼트 값, 벡터 원본, 공식 다운로드/API 및 재배포 조건은 미확인이다.
- 앱 적용: 원본 확보와 사용조건 확인 후 OSM 구간과 길이·방향·위치를 함께 비교하는 교차 검증 후보. 웹 화면의 색만 보고 수치를 생성하지 않는다.

### T03. 국토지리정보원 DEM

- 공식 메타데이터: https://www.data.go.kr/catalog/15059920/fileData.json
- 사용자용 데이터 페이지: https://www.data.go.kr/data/15059920/fileData.do
- 확인: 국토지리정보원 수치표고모델, IMG 형식, 무료 표기, 카탈로그 이용허락범위 제한 없음. 국토정보플랫폼의 대용량 전송 소프트웨어 사용 안내가 있다.
- 카탈로그 게시일 2024-09-24, 수정일 2025-06-17. 특정 도엽의 실제 촬영·제작일이 아니다.
- 확보 수준: 공식 JSON 카탈로그 본문 열람. 도엽 파일 미확보. 학교 주변의 제공 해상도, 최신 제작연도, 로그인 요구 및 실제 다운로드 절차는 검수하지 못했다. 이 카탈로그만으로 1m/5m DEM을 공개 다운로드할 수 있다고 단정하지 않는다.
- 국토정보맵 페이지 직접 열람은 웹 도구에서 400 오류였다: https://map.ngii.go.kr/ms/map/NlipMap.do
- 앱 적용: 대상 도엽의 격자·높이기준·품질과 이용조건을 확인한 뒤 지형 추정의 입력으로만 사용. 저해상도 DEM을 보간해 픽셀 수를 늘려도 보도 수준 정확도가 생기지 않는다.

### T04. DEM 도엽별 성과 메타데이터

- 공식 JSON: https://www.data.go.kr/catalog/15067637/fileData.json
- 데이터 페이지: https://www.data.go.kr/data/15067637/fileData.do
- 확인: CSV 형식 도엽별 성과 내역으로 도엽번호, 원시자료 제작연도, 격자간격, 좌표계, 표고기준, 정확도 등의 필드가 제공된다고 설명한다. 카탈로그 이용허락범위 제한 없음.
- 자료명에 20231107이 있으나 카탈로그 수정일은 2025-07-10이다. 개별 도엽의 유효 시점은 행 단위 확인이 필요하다.
- 확보 수준: 필드 정의 열람. CSV 실파일·서울 대상 행은 미확보. 이 메타데이터 자체가 고도 래스터는 아니다.
- 앱 적용: T03 도엽 선택 전 필요한 검수표. 원시자료 획득방법과 실제 제작일을 기록하고 서로 다른 수직기준의 자료를 그대로 혼합하지 않는다.

### T05. 서울시 S-MAP 경사·표고 분석

- 공식 가이드: https://smap.seoul.go.kr/guide/guide.html
- 확인: 시작·끝 지점을 선택하는 지형 경사도 분석과 지점 표고 측정, 연도별 배경지도/3D 건물 선택 기능이 안내되어 있다.
- 확보 수준: 공식 사용 가이드 열람. 학교 주변 지점 측정, 측정 정확도·표고 원본 시점, 수치 추출 API와 데이터 재배포 권한은 미확인이다.
- 앱 적용: 대표 경로의 육안 비교와 이상치 점검 도구 후보. 가이드가 있다는 것과 학교 주변의 보도면 높이를 확인했다는 것은 구분한다.

### T06. DEM 제작 기준 — 해상도와 높이 정확도 구분

- 현행 규정 페이지(2026-01-13 시행 표시): https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000272806&chrClsCd=010201
- 실제 열람한 품질관리표 PDF: https://www.law.go.kr/LSW/flDownload.do?bylClsCd=200203&flNm=%5B%EB%B3%84%EC%A7%80+5%5D+%EC%88%98%EC%B9%98%ED%91%9C%EA%B3%A0%EB%AA%A8%ED%98%95+%EC%A0%9C%EC%9E%91+%ED%92%88%EC%A7%88%EA%B4%80%EB%A6%AC%ED%91%9C&flSeq=161554295
- 표에는 1m 격자 높이 RMSE ±0.5m/최대오차 ±0.75m, 5m 격자 RMSE ±1.0m/최대오차 ±2.0m라는 검사 기준이 기재되어 있다. **학교 도엽의 실제 성능을 검증한 숫자가 아니다.** 다운로드한 서식이 현행 규정의 최신 첨부인지도 적용 전에 대조해야 한다.
- 추론: 1m 격자라는 이유로 수 cm 턱을 판별하거나 몇 m 길이 경사로의 완만함을 보장할 수 없다. 예를 들어 높이차 0.5m는 10m 구간에서 5%에 해당하므로 짧은 구간의 경사 계산은 높이 오차에 민감하다. 이것은 단순 민감도 예시이며 실제 오차분포나 확률 보장은 아니다.

## 데이터로 만들 때의 절차

1. T01 원본 ZIP과 T03/T04 대상 도엽의 실제 파일을 확보해 해시, 라이선스, 촬영·제작일을 기록한다. 페이지 갱신일을 측량일로 복사하지 않는다.
2. `.prj`와 높이 필드 단위·수직기준을 확인해 미터 기반 투영좌표계로 계산한다. 좌표계는 파일 검수 전 임의 지정하지 않는다.
3. 기존 OSM의 `bridge`, `tunnel`, `layer`, `highway=steps`, 고가·지하 시설 연결을 별도로 표시한다. 지표면 기반 지형고도를 교량 바닥/지하도 바닥 높이로 대입하지 않는다.
4. 도로 선형을 원본 해상도에 맞게 표본화하고 `100 * 높이차 / 수평거리`로 방향을 가진 종단 경사를 계산한다. 왕복 간선에는 오르막/내리막 부호를 반대로 저장한다. 전체 시작·끝 높이만 사용하면 중간 급경사가 상쇄된다.
5. 최대·평균·누적 상승량은 산출 구간 길이와 보간법을 함께 보관한다. DEM의 최대 하강 방향인 면 경사와 실제 길 진행 방향의 경사를 구분한다.
6. 지형 기반 값은 `estimated_from_contours`/`estimated_from_dem`으로 분류한다. 기존 `incline` 값과 출처 없이 덮어쓰지 않는다. 오차가 임계 판단을 바꿀 수 있으면 미확인 상태를 유지한다.

권장 기록 필드: `osm_way_id`, `from_node`, `to_node`, `geometry`, `source_url`, `source_dataset_id`, `source_date`, `retrieved_at`, `evidence_type`, `resolution_m`, `vertical_datum`, `slope_pct`, `sample_length_m`, `method`, `uncertainty_note`, `bridge_tunnel_excluded`, `field_verified_at`. 확인하지 못한 값은 null로 둔다.

## 남은 현장 확인

- 학교 교문·정류장·횡단보도 진입부: 짧은 경사로의 최대 종단 경사와 횡단 경사, 턱 및 배수 홈.
- 종월2교 등 교량: 보행면 높이, 양쪽 접속 경사로, 계단과 우회 연결. 지표 DEM 기반 추정을 직접 적용하지 않는다.
- 벤치 경유 연결: 보도에서 벤치까지의 실제 진입 경사와 노면. 가까운 좌표만으로 진입 가능 판정 금지.
- 같은 도로의 좌·우 보도: 종단 경사는 비슷해도 횡단 경사·차량 출입 경사로가 다를 수 있다.
- 공사·포장 변경·임시 폐쇄는 원본 제작 후 달라질 수 있으므로 확인일과 위치를 남긴다.

## 접근 한계

웹 검색/열람 도구로 공식 페이지와 JSON·PDF를 확인했다. 공공데이터 일반 상세 페이지 일부는 웹 도구의 `Unsupported content-type: text/markdown` 오류가 있어 공식 JSON 카탈로그로 내용을 확인했다. 실행 환경의 셸 HTTP 정책에는 서울시·국토지리정보원 도메인이 포함되어 있지 않으며, 이를 우회해 원본 다운로드를 시도하지 않았다. 따라서 **확보 상태는 메타데이터·명세 확인**이며 도엽/공간 레코드 확보가 아니다. 다른 담당자가 허용된 도구로 원본을 확보하면 그 결과를 우선해 이 상태를 갱신해야 한다.

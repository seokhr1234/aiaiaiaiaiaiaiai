# 가중치 없는 광역 검토 그래프 — 2026-11-11 KST

같은 OSM 원본의 way와 round7에서 복구한 도로 노드 태그로 만든 **검토 전용 위상 자료**다. 앱의 활성 보행 그래프가 아니다. 기존 round3~round7과 런타임 자료·실행 파일을 보존한다. 새 외부 원본을 수집한 것이 아니라 같은 PBF를 추가 처리했다.

원본 [Geofabrik/OSM](https://download.geofabrik.de/asia/south-korea.html), ODbL-1.0, **수집일 2026-11-11 / 데이터 기준 2026-11-09T21:22:17Z**, EPSG:4326 경도·위도, 수직 기준 null/미확인을 유지한다. 원본 SHA-256 `4e44c2315ea171b0c9041e9ea625865163fddaf9325d146884dd00ba9a17484d`, 입력 압축본 해시는 결과 JSON에 고정한다. `[126.7,37.38,127.3,37.78]` 사각 범위에 겹치는 way가 대상이며 서울 행정 경계 내 전수망이 아니다.

원본 way의 인접 노드만 선분으로 만들며 좌표 근접 스냅·임의 횡단·출입구 연결·지명 하드코딩은 하지 않는다. 같은 ID/같은 좌표의 퇴화 구간도 연결을 새로 만들지 않는다. 후보에 남지 않은 way와 선분은 사유·원본 태그/ID로 별도 보존한다.

`foot` 우선의 원문 주장과 일반 `access`를 구분하고 금지·이용자 제한·다른 보도 사용·미해석·조건/보행 방향이 남으면 보류한다. `cycleway`는 **명시적 `foot` 긍정 태그**가 있어야 후보로 남긴다. 일반 차량 `oneway`를 보행 방향으로 옮기거나 일반 차량 turn restriction을 보행에 일괄 적용하지 않았다. 출입 권한의 지역별 법적 기본값은 결정하지 않았으며 단순 태그가 없는 길도 통행 허가로 확정하지 않는다.

교량/지하/지상 아닌 층위·실내/위치·기계 연결 태그와 차단물은 검토가 끝날 때까지 보류한다. 낮은 턱이나 `foot=yes`인 게이트도 현장 통과를 확인한 것으로 보지 않는다. 계단 후보에는 계단 표시를 남기고 way와 양 끝 노드의 `wheelchair` 원문을 보존한다. 경사 태그는 **원문만** 남긴다. 거리/시간/경사 가중치 0건, 좌표 스냅 0건, 추정 횡단 0건, 새 경사 승격 0건이다.

## 검증과 v1 보존

[v2 결과](study-graph-v2-results.json)와 [독립 검증](validation.json)은 압축/원문 해시·전체 후보 좌표/노드 순서·원본 태그·제외/후보 중복/누락·모든 비퇴화 선분의 처리 여부를 확인한다. 빌더는 배열 기반 연결 성분을, 독립 검증기는 원래 OSM ID를 키로 한 사전 기반 성분을 집계해 성분 수·사용 노드 수·상위 20개 크기를 대조했다. 원본과 다른 좌표·누락 노드·중복 way는 성공 결과로 내보내지 않는다.

`test_study_graph.py`는 같은 좌표/다른 노드 ID의 비결합, 차단물·노드 층위·명시적 cycleway 보행 태그·일반 차량 방향 미전용·조건부 보류·끝점 휠체어 태그 보존·원본 불변·손상 입력의 부분 성공 금지를 검사한다.

첫 v1은 일반 `access=yes`를 cycleway의 명시적 `foot`와 충분히 구분하지 않고, 노드만의 일부 구조물 태그를 놓칠 수 있었다. v2에서 정책을 보강했다. v1 결과·압축본·당시 스크립트를 삭제하지 않고 **잠정/대체됨**으로 보존한다. [v1 검토 사유](v1-review-findings.json), [v1 잠정 집계](study-graph-results.json). v1을 활성 자료나 검증 완료로 사용하지 않는다. 현재 재현 스크립트의 기본 출력은 `derived-v2/`와 `study-graph-v2-results.json`이다.

큰 원본·파생본과 v1 스크립트 사본은 `derived/`·`derived-v2/`에 무손실 gzip/원문으로 로컬 보관하고 Git 제외한다. Git에는 코드·정책·집계·해시·검증을 남긴다. 원본이 없는 환경에서 확보 완료로 간주하지 말고 round5/round7 원본·파생본을 재수집/재현·해시 검증해야 한다. v2 후보/제외 압축본은 각각 28,875,468 / 718,551 bytes다.

```sh
python3 research/accessibility/round8-2026-11-11/test_study_graph.py
python3 research/accessibility/round8-2026-11-11/build_study_graph.py
python3 research/accessibility/round8-2026-11-11/validate_study_graph.py
```

출력이 있으면 빌드는 중단한다. 새 사본/새 조사 경로를 사용하며 기존 결과를 삭제해 실행하지 않는다.

## 적용 전 남은 일

이 자료에 새 정밀지도/건물 겹침 필터·보도 중심선·평행 보도 연결·턱/유효 폭·실측 경사·운영/출입구·역내 환승을 검증해 연결하지 않았다. round6의 제한 관계 구조 신호 628개도 해결 완료로 바꾸지 않았다. 지붕/덮개·복합 구조물·다층 접속과 조건부/방향별 정책도 실제 자료와 함께 추가 검토해야 한다. 제외로 인한 4,374개 성분을 좌표 스냅이나 가짜 연결로 합치지 않는다.

활성 엔진은 계속 기존 월곡 범위를 사용한다. 이 연구 그래프는 `field_verified:false`, `routing_eligible:false`, `active_runtime_replaced:false`, `citywide_routing:false`다. 다음은 성분/경계 분리 사유·건물/보도·구조물 층위 검토와 검증된 시범 부분의 버전 고정 이관이다. [전체 완료·남은 계획](../../../donghaeng-nav/docs/seoul-expansion-progress.md).

## 네트워크 실패와 미수집

[환경 확인](environment-observation.json): HTTP 무제한 정책이 실제 적용된 상태를 확인했다. 기본 실행 샌드박스의 네트워크 실패 후 지원되는 네트워크 권한을 사용했고, 상속 프록시와 TLS 인증서 검증을 유지했다. 정책 변경·프록시 우회는 하지 않았다.

[기록된 40회 요청](analysis/network-summary.json): HTTP 200 25회, 503 12회, 지도 API 노드 수 초과 400 1회, seq2 POST 전송 중단 2회다. 중단 2건의 초기 수집기는 응답 읽기 실패 후 status를 null로 기록했으며 `IncompleteRead`와 앞서 받은 응답 헤더가 남아 있다. 부분 바이트는 복구하지 않았고 별도 성공한 GET 원본만 검증했다. 이후 수집기는 향후 부분 응답을 별도 파일에 보존하도록 개선했다.

- 이전의 CONNECT 403은 이번 서울시·OSM·Overpass 실제 자료 요청에서 재현되지 않았다. Overpass 상태 URL의 초기 단순 확인은 406이었지만 실제 interpreter POST는 성공했다.
- 서울시 API는 공식 문서에 안내된 **HTTP 8088** 표본 요청에서 정상 JSON을 반환했다. HTTPS 8088 및 HTTPS 기본 포트 시도는 503이다. 전체 API를 받은 것으로 표시하지 않았다.
- NGII DEM 카탈로그 `15059920`, 성과내역 `15067637`, 국토정보플랫폼 메인/지도, NGII 고시와 서울안전누리는 503 오류 본문을 보존했다. 주로 upstream 연결 timeout이며, 실제 서비스 전체 장애나 자료 부재의 증거가 아니다.
- NEINS 안내 HTML을 얻었지만 대상 지역 래스터 원본·도엽·수직 기준·측량 정확도는 확보하지 못했다. 5m 안내를 해당 지역 다운로드 완료나 보도 경사로 채택하지 않는다.

## 보존·재현·검증

`raw/<request-id>/request.json`은 원본 응답 메타데이터이고 `response.bin`은 수신 바이트 그대로다. CSV는 CP949로 해독하고 원본 인코딩을 보존했다. 대용량 ZIP·OSM 원본과 재생성 가능한 선택 GeoJSON은 **이 작업 공간에 보존하되 이 폴더의 .gitignore로 Git에서 제외**한다. 요청 계획·해시·작은 원문·분석 결과·스크립트는 남긴다. 다른 환경에서 원본이 없으면 획득 완료로 간주하지 말고 새 요청 ID/새 수집 폴더에 실제 재수집해야 한다.

```sh
python3 -m pip install -r research/accessibility/round4-2026-11-05/requirements.txt
python3 research/accessibility/round4-2026-11-05/analyze.py
python3 research/accessibility/round4-2026-11-05/validate.py
```

수집은 `collect.py <plan-*.json>`으로 재현할 수 있다. **동일 요청 ID 폴더가 있으면 중단**해 기존 응답을 덮어쓰지 않는다. 새 조사는 ID를 바꾼 계획을 만든다. 네트워크 정책·추가 실행 권한은 각 환경에서 확인해야 한다. 원본과 메타데이터를 받은 뒤에만 분석하며 200 상태만으로 정상 데이터라고 판정하지 않는다.

[검증 기록](analysis/validation.json)은 원본 해시·건수·중복·좌표·전체 CSV/API 건수 대조, ZIP CRC·PRJ·seq2 재추출 일치, OSM 대조와 기존 research 전체 파일·런타임 자료 9개·보호 코드 13개·기존 HTML 보존을 확인한다. 앱 소스/화면/HTML을 바꾸지 않아 새 빌드·브라우저·GPS 테스트는 수행하지 않았다. 현장 통행·실제 전화기 GPS 검증은 여전히 미완료다.

다음 단계는 NGII 연결 재확인 후 해당 도엽의 5m 이하 DEM 또는 원본 DXF/XML·측량 연혁·수직 기준을 함께 확보하고, 운영시간이 다른 두 쉼터의 현재 안내와 정확한 출입구·층을 확인하는 것이다. OSM 노드열이 달라진 5개 도로는 기존 그래프·표고 연결을 다시 검증한 후에만 별도 적용을 검토한다.

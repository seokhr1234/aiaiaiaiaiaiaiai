### 수집 및 이전 과정

초기 조사 환경에서는 네트워크 정책 때문에 공식 원본 다운로드가 막혔다. 후속 채팅 **학교 주변 API 수집 재개**의 허용된 환경에서 2026-10-31 **21:15:35~21:20:40 KST**에 실제 수집이 수행됐다. 이후 사용자가 경량 ZIP을 이 프로젝트에 첨부했다.

현재 저장소에는 [acquired-2026-10-31](acquired-2026-10-31/README.md)의 보고서·CSV·GeoJSON·요약·요청 로그·해시 목록 **29개 파일**이 실제로 들어와 있다. ZIP은 1,371,515 bytes이고 SHA-256은 다음과 같다.

```text
4b6e87bef591708686d49d60d2c64bd3b4db81fac2516aa798da24fd830cd2ae
```

경량 ZIP에는 대용량 원본이 빠져 있었으나 이후 전체 ZIP의 분할 파일 4개를 추가 전달받았다. 복원한 전체 ZIP은 **101,459,385 bytes**, SHA-256 `8a4038fc1a5bac69c47edce1d5d92dc3d2196f105fd11c24f50975dde0d32456`으로 이전 대화의 기록과 일치한다. 179개 파일을 별도 폴더에 해제했으며, 원본 GIS ZIP·전체 XLSX/CSV·HTTP body·수집/분석 스크립트가 이제 이 환경에도 있다. 첨부 스크립트는 실행하지 않았다. 설치 의존성은 전체 ZIP에도 포함되지 않았다.

## 4. 학교 주변 횡단보도

WGS84 경위도에서 학교 기준점까지의 타원체 거리를 다시 계산했다. 포함된 1,260행 모두 2,000m 이내였고, 가장 먼 행은 약 1,999.38m였다. 저장된 거리와 재계산값은 소수 둘째 자리 반올림 오차 범위에서 일치했다.

| 구분 | 건수 |
| --- | ---: |
| 성북구 | 788 |
| 동대문구 | 453 |
| 강북구 | 19 |
| 보행등 Y / N | 367 / 893 |
| 음향신호기 Y / N | 315 / 945 |
| 고원식 Y / N / `-` | 132 / 1,012 / 116 |

`-`는 N으로 바꾸지 않았다. 신호등·음향신호기·고원식 표시는 각각의 시설 속성이며, 휠체어 진입부의 턱 낮춤·실제 잔여 턱높이·단차 없는 연속 접속을 확인한 값은 아니다.

지역 CSV의 **608행**은 OA-23081과 관리번호가 일치했고 보행등 유무도 일치했다. **652행**은 결합되지 않았다. 이 차이는 자료 범위·기준일·관리 갱신 차이일 수 있으므로 시설 철거·오류로 단정하지 않는다. 두 자료가 같은 관리체계에서 나왔을 수 있어 608개를 독립 현장 검증으로 세지 않는다.

두 경로의 중심선에서 20m 이내 후보는 **15행**이다. 직접 거리 계산으로 재확인해 [route-crossing-candidates.csv](route-crossing-candidates.csv)에 정리했다. 예를 들어 `06-0000024261`은 약 0.26m, `06-0000023127`은 약 6.89m 거리지만 같은 보행면·실제 횡단 구간인지의 확인은 남아 있다. 도로 중심선에 가까운 시설 점을 자동으로 경로 간선에 붙이면 고가·하천변·교량의 층 관계를 잘못 연결할 수 있다.

원본 품질 문제도 보존했다. 최초 HTTP 200 CSV는 중간 행에서 끝나 재요청한 기록이 있다. 이번에는 재수집 원본의 **40,282행 전부**를 직접 읽어 필드 구성이 완전한지 확인했다. 좌표가 빈 원본 39,696번째 줄 1행을 확인해 공간 선택에서 제외했고, 전체 자료에서 2km 선택을 다시 실행해 1,260행과 원본 속성을 재현했다. 파일의 구조적 완전성은 현장 시설 전수조사의 완전성을 뜻하지 않는다.

## 6. 경사·지형

수집 당시 OA-22241 ZIP 45,852,601 bytes의 SHA-256은 `4fbe3c7e061b5974e7403ec116855304ed8ae321eebcc0d12c31ca8fb7be30bf`로 기록됐다. 당시 원본 PRJ를 읽어 수평좌표계 EPSG:5174를 확인하고 WGS84 및 EPSG:32652로 변환해 학교 2km 영역을 선택했다. 추가 전달된 원본 ZIP에서도 CRC·PRJ·DBF를 직접 검사하고, 원본 등고선 8,570개·표고점 45,870개에서 2km 선택을 다시 실행했다. 원본 레코드 ID와 속성은 추출본과 모두 일치했고 클리핑 기하의 UTM 거리 차이도 0.01m 미만이었다. 이는 재현 일치 허용오차이며 원천 측량 정확도가 아니다.

| 레이어 | 원본 레코드 수(당시 검사) | 이번 추출본 | 추출본 HEIGHT 범위 |
| --- | ---: | ---: | --- |
| 등고선 `N3L_F001` | 8,570 | 151 | 15~140 |
| 표고점 `N3P_F002` | 45,870 | 727 | 13.54~136.69 |

원본 속성 설명문과 SHP XML도 확인했다. 설명문은 CONT를 등고수치, NUME를 수치로 설명하나 HEIGHT의 수직 단위·기준은 명시하지 않았다. XML의 생성·복사 처리 날짜는 현장 측량일로 사용하지 않았다.

위 HEIGHT는 **원본 속성값**이다. 수평 PRJ의 Meter 표기만으로 HEIGHT의 수직 단위·높이 기준을 독립 확정하지 않았다. 따라서 표의 값에 임의로 m를 붙이거나 서로 다른 고도 자료와 보정 없이 섞지 않는다. 원본 전체의 높이 범위와 학교 추출본의 범위도 구분한다.

등고선은 UTM에서 256변으로 근사한 2km 원형으로 클리핑했고 표고점은 같은 영역으로 선택했다는 검사 기록이 있다. 이는 횡단보도에 사용한 WGS84 타원체 거리와 경계에서 미세한 차이가 날 수 있다. 이번 검증에서 도형·좌표 범위·건수·HEIGHT 최소/최대와 `derived_slope_pct=null`을 확인했다.

새로 계산한 구간별 경사 수치는 **0개**다. 추후 지형 표면을 만들더라도 길 진행 방향의 종단 경사와 지형 면 경사, 평균 경사와 짧은 최대 경사, 종단 경사와 보도 횡단 경사를 구분해야 한다. 구월교와 지하 구간의 보행면은 지표면 고도와 달라 DEM/등고선 높이를 직접 대입하면 안 된다.

## 7. 경로·출입·시설 연결

### 현재 경로와 기존 저장본

후속 수집 원본을 직접 읽어 경로 15way의 태그·노드 순서가 기존 저장본과 같은지, 이력의 최종 버전이 당시 조회한 버전과 같은지 재검증했다. 66개 부분 간선이 원본 way의 연속 노드 쌍인지도 대조했고, 거리는 좌표에서 별도로 재계산했다. 이번 검수에서 실시간 API를 다시 호출한 것은 아니다.

| 항목 | 거리 우선 | 벤치 경유 |
| --- | ---: | ---: |
| 실제 부분 간선 수 | 30 | 36 |
| 이번 타원체 거리 재계산 | 673.93m | 957.31m |
| 종전 엔진의 거리 계산 | 673.97m | 957.79m |
| 수치 incline가 등록된 경로 way | 0 | 0 |

거리의 작은 차이는 계산 방식 차이이며 지도 변화의 증거가 아니다. 이 거리에 출발·도착의 미검증 직선 연결이 안전한 보행 구간으로 검증되어 추가된 것은 아니다.

시작점 `14196290450`과 목적지 `357869790`는 각각 학교 이름의 정류장과 '종월2교' 정류장/platform 객체다. 실제 경유 교량은 구월교 `379766295`이며 목재 노면·보행 지정·차량 금지 태그가 있다. 두 경로는 터널 `750640242`를 공통으로 통과한다. 수집 기록은 이 원시 태그를 재확인했지만, 정류장→그래프 **20.50m·17.11m**, 벤치 접속 **2.18m**의 실제 통행 가능성은 해결하지 못했다.

기존 위상 분석의 공통 터널 약 14.69m, 마지막 8간선 약 102.14m는 우선 확인할 대상이다. 현재 채택 그래프에서 대체 연결이 없다는 뜻이며 실제 보도의 폭이 좁거나 현장에 우회로가 전혀 없다는 뜻은 아니다.

### 독립 OSM 시설 추출

경로 주변 bbox에서 추출한 대상 171개에는 entrance 103개, crossing 태그 64개, barrier 1개, kerb 0개가 있다. 태그는 중복될 수 있고 `highway=crossing` 또는 elevator 등 다른 선택 조건도 있으므로 태그별 수를 단순 합산하지 않는다. GeoJSON은 Point 151개와 LineString 20개이며 범위는 학교 2km 전역이 아니다.

경로 중심선 20m 이내 대상은 entrance node `14196290228`(14.58m), `14196290475`(14.81m) 두 개다. 가까운 출입구라는 사실이 학교 정문·일반인 개방·무단차 접속을 뜻하지 않는다. `kerb` 0건도 실제 턱 없음의 증거가 아니다.

### 승강기·임시폐쇄

공개 sample 35항목은 응답 구조를 확인하는 데 유용하지만 월곡·고려대·안암·상월곡 등 인근 역의 모든 설비와 폐쇄 정보를 확보한 결과가 아니다. 일부 응답에 청량리가 포함돼도 그 역 전수·현재 가동 확인으로 확대하지 않는다. 좌표 WKT, 시설 일련번호, 출입구·층·방향, 상태코드, 관측시각과 보도에서의 실제 진입을 함께 연결해야 한다. 에스컬레이터를 휠체어용 엘리베이터 대체 경로로 사용하지 않는다.

이번 보고서는 연구·자료 정리 결과다. `server.mjs`, 경로 엔진, 제품 화면, 배포, Git 커밋 및 원격 저장소는 변경하지 않았다. 사용자 계획에 따른 Node 서버 전환은 별도 구현 작업이다.

# 2차 출입·시설 연결 심층조사

조사일: 2026-10-31 (한국 시간). 범위: 서울사대부중 기준점 `(37.5950991,127.038992)` 주변 약 2km 및 월곡·고려대·안암·상월곡 등 인근 역. 이 기준점은 교문 실측 좌표가 아니다.

## 이번에 발전한 결과

1차의 출처 소개 수준에서 나아가 **공식 문서에 기재된 서비스명·필드·상태코드·층 연결 조합**을 확보했다. `api-schemas.json`에 정리했고 공식 `sample` 키로 최대 5행만 조회하는 재실행 스크립트도 작성했다. 다만 실제 API 응답 행과 신규 XLSX·CSV·안내도 원본은 아직 확보하지 못했다. 학교·주변 역의 현재 출입이나 승강기 정상운행을 새로 검증했다고 주장할 수 없다.

- 공식 출처 후보 18개와 확인 수준은 `sources.json`에 기록했다. 후보 수와 데이터 취득 건수는 다르다.
- 원본 미확보 자료의 `raw_bytes`, `raw_sha256`은 `null`이다. 웹 도구가 추출한 텍스트를 원 HTTP 파일인 것처럼 해시하지 않았다.
- 기존 사용자가 업로드한 에스컬레이터 원본은 실제 바이트와 SHA-256을 `existing-artifacts-manifest.json`에 남겼다. 4개 역 설치기록 36행을 `nearby-existing-installations.json`으로 정리했으나 **새 다운로드가 아니다**.
- 네트워크/도구 실패는 `acquisition-log.json`에 기록했다. 접속 실패는 승강기 고장이나 출입구 폐쇄를 뜻하지 않는다.

## 1차 해석 정정: 종월2교는 목적지 객체를 먼저 구분

이번 팀 교차 검증에서 실제 기본 목적지 `종월2교`는 OSM `node/357869790`의 버스정류장/플랫폼 객체로 확인됐다. 1차 보고서가 이름만 보고 암시했던 '교량 양쪽 접속부' 해석은 이 목적지에 적용하면 안 된다. 실제 벤치 경유 경로에서 지나가는 교량은 `way/379766295` 구월교이고, 공통 경로에 `way/750640242` 터널이 있다. 이 식별자는 팀의 로컬 OSM 원본 분석 결과이며, 이번 에이전트의 신규 현장 관찰은 아니다. 상세 근거는 round2 교차 검증 결과를 따른다.

따라서 현장 확인 우선대상은 '종월2교라는 이름의 다리'가 아니라 **정류장 플랫폼→보도 접속, 실제 구월교의 접속부, 터널 진출입부**다. 옛 교량 통계에서 동명의 교량을 찾더라도 기본 목적지와 동일 객체라고 결합하지 않는다.

## 학교·도서관·공원 출입 조건

- 학교 공식 사이트 `https://www.snu.ms.kr/`는 도구 접근 실패였다. 교문별 일반인 출입·운동장 개방 규정을 확보하지 못했고 블로그 개방 경험은 채택하지 않았다. 학교를 통과 지름길로 허용할 근거가 없다.
- 오동숲속도서관의 운영기관 `https://www.sblib.seoul.kr/odlib` 역시 이번 접근이 실패했다. 1차에 확인한 [한국관광공사 공식 편의안내](https://access.visitkorea.or.kr/ms/detail.do?cotId=172646e9-64ae-4a93-8aa3-69a1b517158a)의 자동문·장애인 주차·화장실, 통상 시간·재난 시 공원통제 조건은 시설 안내 근거로 남긴다. 현재 운영기관의 예외 휴관일을 이번에 재검증하지는 못했다.
- 자동문은 단차 없음·문폭 충분·공원에서 연속 접근 가능과 별개다. 정류장·도로→공원 진입→도서관 문, 각 구간의 경사·턱·폭이 확인되어야 한다.
- 시설 운영시간은 공원 통과 시간이나 외부 휴식공간 개방시간과 동일하다고 간주하지 않는다. 도서관 주소를 가장 가까운 도로에 단순 직선 연결하지 않는다.

## 확보 시도와 재현

실행 환경의 정책 스냅샷은 package_managers만 허용하고 있었다. 공식 포털을 상속 프록시로 읽은 실제 시도는 `Tunnel connection failed: 403 Forbidden`이었다. 설정을 바꾸거나 프록시를 제거하지 않았다. 웹 도구로 공식 사이트 조사와 명세 확인을 이어갔다. 공개 JS와 다운로드 POST의 공식 경로 검증은 원 HTML을 읽을 수 없어 완료하지 못했다.

공식 데이터셋의 예제는 `http://openapi.seoul.go.kr:8088/(인증키)/...` 형태이고 [공식 이용안내](https://data.seoul.go.kr/together/guide/useGuide.do)는 공개 예제 문자열 `sample`로 1~5행 조회를 안내한다. 이 범위의 요청을 `acquire-public-samples.py`에 구현했다. 현재 실행한 검증은 `--dry-run`이며 실제 HTTP 요청 성공을 뜻하지 않는다. 웹 도구로 두 샘플 URL을 열어본 시도는 URL/ref 해석 오류였고, 서비스 자체 응답으로 기록하지 않았다.

호스트 허용이 실제로 적용된 후 다음 명령으로 원본 응답·최종 URL·HTTP 상태·바이트·SHA-256·API 결과코드·행 수를 별도 다운로드 폴더에 기록할 수 있다.

```sh
python research/accessibility/round2/entrances/acquire-public-samples.py
```

스크립트는 로그인/키발급 없이 공식 샘플 요청만 하며, 상속 프록시·CA를 유지한다. `sample`은 최대 첫 5행이므로 이 결과만으로 학교 주변 전수 목록을 만들 수 없다. 지역 필터의 실제 적용과 전체 자료 조회에는 공식 명세에 맞는 인증/공개 다운로드가 추가로 필요하다.

## 앱 데이터로 연결할 때의 결론

확보가 필요한 조합은 **공간 좌표(WKT) + 설비번호/층 연결 + 가동상태와 관측시각 + 출입구 폐쇄 + 실제 외부 보도 접속**이다. 순서는 다음이 적합하다.

1. 공간자료를 WGS84로 해석해 기존 OSM 출입구와 대조하되 2020 원본의 노후화를 표시한다.
2. EL/ES 설비 일련번호와 관리번호를 보존하고, 근접 출입구를 같은 문이라는 뜻으로 합치지 않는다.
3. 층별 노드와 수직 연결 간선을 별도로 만든다. 각 역의 BM1/BM2 의미는 실제 안내도에서 확인한다.
4. ES 방향/운영상태를 존중하고 휠체어 경로의 EL 대체물로 선택하지 않는다.
5. API 실패·불명확한 join은 `unknown`으로 유지한다. 현재 정상인 설비라도 외부 진입부 턱이나 계단 때문에 도달할 수 없을 수 있다.
6. 기본 정류장 목적지, 실제 경유 교량·터널, 경유 벤치 접속부부터 현장 검증한다. 설치대장과 사진만으로 경로 전체를 '검증 완료'로 바꾸지 않는다.

이번 조사로 새로 통행 가능으로 확정한 도로 간선은 **0개**다. 대신 후속 수집에서 어떤 공식 필드를 어떤 키로 결합해야 하는지, 어떤 제목·좌표·갱신일을 혼동하면 안 되는지를 구체화했다.

## 수집 결과

- 서울시 보행망 공개 sample과 OSM API 모두 HTTP 200을 확인했다.
- 학교 2km 횡단보도 1,260행: 성북구 788, 동대문구 453, 강북구 19. 자료 기준일은 2026-03-20이다.
- 지형 ZIP을 실제 확보하고 EPSG:5174를 PRJ에서 확인했다. 학교 2km 등고선 151개·표고점 727개를 추출했다. HEIGHT의 수직 단위·기준은 독립 확인하지 못했다.
- 월곡로 보도 대장에서 학교를 구간명으로 명시한 4개 행의 폭은 3.0~3.2m다. 대장 기준일은 2025-12-31이고 최소 유효폭·턱높이·장애물 간격을 측정한 값은 아니다.
- 현재 OSM 경로 15way의 태그·노드 순서·기존 경로 노드 좌표가 백업과 같았다. 편집일은 현장 확인일이 아니다.
- 독립 태그 추출의 대상 객체는 작은 경로 주변 bbox에서 171개이며 학교 2km 전체 목록이 아니다. 경로 20m 이내 entrance 2개는 접근가능 여부가 미검증이다.
- 승강기·출입 관련 API 7종에서 sample 항목 총 35개를 받았다. 인근 역 전체의 가동 상태를 수집한 것은 아니다.
- 응답 본문 43개의 해시를 검증했다. 처음 받은 CSV의 잘린 끝부분을 발견해 재수집했으며, 완전한 CSV 40,282행을 확인했다. 좌표 공란 1행은 공간 선택에서 제외했다.

## 남은 제한

- 보행망 sample은 종로구 5행이며 학교 2km의 보행망 행은 0개다. 정식 인증키가 없어 전체 보행망을 수집하지 않았다.
- `SmrtScnFcltsInfo`는 HTTP 200이지만 본문 `ERROR-500`을 두 번 반환했다. 이를 시설 자료 수집 성공이나 시설 고장으로 해석하지 않는다.
- 경사·최소 유효폭·턱·현재 통행 및 출발/도착/벤치의 직선 연결은 현장 미검증이다.
- 횡단보도 두 자료의 관리번호 608개가 일치했지만 같은 관리체계에서 왔을 수 있어 독립 현장 검증으로 세지 않는다.
- 최초 네트워크 실행 권한 오류 2건은 해결되었고, 이후 원본 취득은 다른 실행 환경의 허용된 정상 프록시를 사용했다.

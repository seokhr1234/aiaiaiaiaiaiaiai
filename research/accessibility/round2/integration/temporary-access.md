# 임시 공사·통제 정보의 추가 조사

조회일: 2026-10-31 (Asia/Seoul). 이 문서는 통합 담당이 네 전문 담당의 조사에 더해 확인한 공식 출처다. 학교 주변의 현재 공사·폐쇄 행을 확보한 결과는 아니다.

## 도로굴착 공사 원장

[서울시 도로굴착 공사 현황 OA-22901](https://data.seoul.go.kr/dataList/OA-22901/S/1/datasetView.do)은 착공계가 접수되고 허가가 승인된 굴착 공사를 제공한다고 설명한다. 포털은 매일 갱신과 공공누리 1유형을 표시한다. 조회 시 갱신일은 2026-10-31, 메타 수정일은 2026-04-14였다.

공식 페이지의 파일 목록에는 파일이 없고 Sheet/Open API가 표시된다. 실제 CSV 행·응답 스키마·주소 또는 좌표 필드는 확보하지 않았다. 따라서 특정 도로를 공사 중으로 표시하거나 위치를 추정하지 않았다. 공사가 기록되어 있더라도 보도가 폐쇄되었는지는 별도 확인 대상이다.

[공공데이터포털 15052469](https://www.data.go.kr/data/15052469/fileData.do)는 같은 자료로 연결되며 자료명에 20260630을 표시한다. 이 카탈로그 날짜와 서울시 서비스의 매일 갱신 표시는 구분한다. 카탈로그의 전체 행 1은 학교 주변 공사가 한 건이라는 뜻으로 쓰지 않는다.

[도로굴착복구 대민서비스](https://roaddig.seoul.go.kr/intro/main.do)는 허가공고·사업계획·굴착공사·도로돌발 조회 메뉴를 제공한다. 메인 공지에 2026-06-10 성북구 하반기 사업계획 신청 공고가 있으나, 이 공지는 특정 구간의 실제 착공·폐쇄·준공 증거가 아니다. 조회 화면의 학교 주변 행은 미확보다.

## TOPIS 돌발·통제 API

[실시간 돌발 정보 OA-13315](https://data.seoul.go.kr/dataList/OA-13315/A/1/datasetView.do)는 서울시 도로 사건을 제공한다. 실시간 갱신, 공공누리 1유형, 원천 TOPIS를 명시한다. 공개 문서에서 서비스 `AccInfo`와 다음 필드를 확인했다.

- 사건 식별자 `ACC_ID`, 도로 링크 `LINK_ID`
- 발생 `OCCR_DATE`/`OCCR_TIME`, 종료 **예정** `EXP_CLR_DATE`/`EXP_CLR_TIME`
- 유형 `ACC_TYPE`/`ACC_DTYPE`, 설명 `ACC_INFO`
- 좌표 `GRS80TM_X`/`GRS80TM_Y`

확보 수준은 문서 스키마 확인이며 실제 사건 응답은 미확보다. GRS80 TM이라는 이름만으로 EPSG 코드를 확정하지 않는다. 원점·축·단위를 검증한 뒤 변환해야 한다. 자동차 도로의 링크를 OSM 보행 간선과 동일하게 취급하지 않고 실제 영향 구간을 검토한다. 사건 미등록은 보행 통행 가능 근거가 아니며, 종료 예정 시각 경과도 실제 통제 해제 확인과 다르다.

[TOPIS 공식 Open API 안내](https://topis.seoul.go.kr/refRoom/openRefRoom_4.do)는 서울 열린데이터광장의 신청·승인·키 발급 절차를 안내한다. TOPIS 일반 안내의 비영리 표현과 데이터셋별 공공누리 표시가 함께 존재하므로 운영 서비스에 적용할 때 해당 API의 이용조건을 재확인한다. 이번 조사에서는 계정·키를 발급하거나 기관에 연락하지 않았다.

## 연동 시 필요한 검토

1. 원장과 사건 응답을 시각·원본 식별자와 함께 캐시한다. 예정일·관측일·조회일을 별도로 저장한다.
2. 공식 좌표가 없으면 행정동 중심에 점을 만들어 도로를 폐쇄하지 않는다. 도로명 지오코딩은 검토 후보로만 남긴다.
3. 차량 통제, 보도 점유, 보행 전면폐쇄, 일부 차로 점유를 구분한다. 단순 공사 존재만으로 모든 보행 경로를 제거하지 않는다.
4. 명시적 보행 통제가 있으면 실제 구간·기간과 대체 동선을 확인한다. API 실패·오래된 응답은 `unknown`으로 표시한다.

## 학교 주변 공사 검색의 결과

회기로5길·월곡로8길·구월교·종월2교 이름과 공사/통행/2026 키워드로 공개 검색을 수행했다. 검색 결과에는 민간 입찰 집계와 타 지역의 동명 도로가 섞여 있었다. **학교 경로와 정확히 대응하는 공식 현재 통제 공지는 확인하지 못했다.** 검색 실패는 통제 없음의 증거가 아니며, 민간 사이트의 주소를 원본 확인 없이 도로 속성으로 채택하지 않았다.

# API 재시도 결과

2026-10-31, 사용자가 인터넷 접근 허용 설정을 변경했다고 알려준 뒤 현재 실행 환경에서 다시 확인했다.

- 서울시 공개 보행망 sample: HTTP 403.
- OSM 터널 way 현재 원본: 프록시 CONNECT 403.
- 서울시 공식 데이터 페이지: 프록시 CONNECT 403.

실제 요청 URL·조회 시각·오류는 attempts.json에 기록했다. 신규 응답 데이터·시설 관측값은 확보하지 못했다. 실패는 API 키 오류나 시설 고장으로 해석하지 않는다.

조회 당시 관리 도구는 observations_current=true, restricted/enforced, package_managers 프리셋, 사용자 지정 allowed_hosts=[]를 보고했다. 사용자 설정 변경이 이 실행 환경에 반영된 상태는 확인되지 않았다. 셸 네트워크 권한을 명시한 정상 프록시 요청으로 확인했으며 프록시 제거·다른 경로로 우회하지 않았다.

1차·2차 기존 실패 기록을 덮어쓰지 않고 이번 재시도를 별도 보관한다.

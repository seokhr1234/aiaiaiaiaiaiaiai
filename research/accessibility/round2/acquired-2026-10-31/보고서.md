# 동행길 API 수집 재개 및 학교 주변 분석

조회: 2026-10-31 21:15:35~21:20:40 KST. 대상: 서울대학교사범대학부설중학교 기준점 `(37.5950991,127.038992)` 주변 2km 및 백업의 기본/벤치 경유 경로.

## 결과

서울시 보행망 공개 sample과 OSM API에 실제 접속했고, 모두 HTTP 200을 받았다. 준비된 보행망·출입시설·OSM·지형 수집 스크립트를 실행해 원본을 확보했다. 공식 페이지의 파일 다운로드 함수·폼·파일 순번을 확인한 뒤 보도·횡단보도 원본도 추가 확보했다. 백업의 실패 기록은 그대로 보존했다.

실제 요청은 45건이다. 이 중 HTTP 응답은 43건이며 모두 HTTP 200이다. 정상 응답 41건에는 문서 HTML과 중복 검증 요청도 포함된다. 2건은 HTTP 200이지만 본문 `ERROR-500`인 서버 오류다. 최초 2건은 실행 네트워크 권한 누락으로 HTTP 요청 전 실패했고, 같은 URL을 명시적 네트워크 권한으로 실행한 뒤 성공했다. 45건을 독립 데이터셋 수나 학교 관측값 수로 해석하지 않는다.

## 학교 주변에서 확인한 내용

### 횡단보도

WGS84 경위도에서 기준점까지 타원체 거리를 계산해 2,000m 이내 1,260행을 추출했다. 성북구 788행, 동대문구 453행, 강북구 19행이며 전부 `데이터기준일자=2026-03-20`이다. 이는 조회일의 현장 상태가 아니다.

- 보행등: Y 367행 / N 893행.
- 음향신호기: Y 315행 / N 945행.
- 고원식: Y 132행 / N 1,012행 / `-` 116행. `-`를 N으로 바꾸지 않았다.
- 현재 OSM 좌표로 복원한 두 기존 경로의 중심선으로부터 20m 이내 후보는 15행이다. 거리상 근접은 같은 층·같은 보도·실제 횡단을 뜻하지 않는다.
- 지역 1,260행 중 608행은 OA-23081과 관리번호가 일치하고 보행등 유무도 모두 일치했다. 652행 미일치는 자료 범위·시점 차이 가능성이 있어 시설 소멸이나 오류로 단정하지 않았다.
- 두 횡단보도 자료는 같은 관리체계 자료일 수 있으므로 608행 일치를 독립 현장 검증 608회로 해석하지 않는다.
- 완전한 CSV에도 경도·위도가 빈 원본 39696번째 줄(연번39695, 중랑구) 1행이 있다. 해당 행은 원본대로 보존하고 공간 선택에서 제외했다.

가장 가까운 기록은 관리번호 `06-0000014860`, 성북구 종암동 7-132 도, 기준점에서 약92.10m다. 원본에는 보행등 N·음향신호기 N으로 기록되어 있다. 학교 출입구까지의 거리나 턱 유무를 뜻하지 않는다.

### 지형

원본 PRJ의 수평좌표계는 EPSG:5174다. 준비된 검수 스크립트로 WGS84 및 EPSG:32652로 변환해 학교2km 원형과 교차하는 등고선151개·표고점727개를 선택했다. 등고선은 원형으로 클리핑했다. 이 원형은 256변 근사이며 점 추출은 경계 부근에서 타원체 거리 방식과 미세한 차이가 날 수 있다.

선택된 `HEIGHT` 값 범위는 등고선15~140, 표고점13.54~136.69다. PRJ의 Meter는 수평 단위이며, 이를 근거로 HEIGHT의 수직 단위·수직기준을 독립 확정하지 않았다. ZIP의 설명문도 함께 검수했지만 HEIGHT 수직기준을 확인하지 못했다. 이 범위를 길 종단경사나 보도 횡단경사로 변환하지 않았다. 교량 구월교와 터널의 보행면은 지표면 높이와 별도다.

### OSM 경로·출입·장벽

경로15way의 태그와 node 순서는 백업과 동일했고, 기존 경로에 사용한 node의 좌표 변경도 없었다. 각 history의 최종 버전은 같은 조회의 현재 버전과 일치했다. 직접 부모 relation 질의도 정상 처리되었으나 결과는 0개다.

기존 경로의 모든 부분 간선은 현재 way의 연속 node 쌍으로 확인됐다. 같은 경로 좌표를 타원체 거리로 합산하면 기본약673.93m, 벤치경유약957.31m다. 백업673.97m/957.79m와의 미세한 차이는 거리 계산 방식 차이며 지도 편집이나 현장 변화의 증거가 아니다. 이 값에는 미검증 출발/도착 연결선을 추가하지 않았다.

경로15way의 수치 `incline`은 0건이다. 구월교 way379766295의 목재 노면·보행 지정·차량 금지, 터널 way750640242의 `tunnel=yes,layer=-1` 태그는 원본에서 재확인했다. 터널 객체의 마지막 편집 시각은 2019년으로, 이번 조회일을 현장 확인일로 사용할 수 없다.

독립 추출 bbox 안 목적 태그 객체는171개다. `entrance`103개, `crossing`64개, `barrier`1개, `kerb`0개이며 나머지는 elevator 등이다. 태그별 수량은 중복 가능하다. 경로중심선20m 안 객체2개는 entrance node14196290228(14.58m),14196290475(14.81m)다. 가까운 출입 태그가 실제 학교 정문이나 무단차 진입을 뜻하지 않는다. kerb 미등록을 무단차의 증거로 쓰지 않는다.

출발 node14196290450와 목적지 node357869790의 정류장 태그도 현재 원본으로 확인했다. 출발20.50m·도착17.11m·벤치연결2.18m라는 백업의 미검증 연결 문제는 해결된 것으로 처리하지 않았다. 최신 원본 수집만으로 실제 연속 통행을 확정하지 않았다.

## 남은 조사

학교 주변 전체 보행망은 정식 인증키 미설정으로 수집하지 않았다. sample의5행만으로 성북구 전체 또는 학교 주변 수집을 완료했다고 하지 않는다. 역 승강기·출입구 폐쇄·공사 sample도 학교 인근 역 전체 조사나 실시간 가동 확인을 대신하지 않는다. 일부 API는 `response.header/body.items.item` 구조여서 백업 수집기의 단순 row 수가 아니라 실제 항목을 별도로 파싱했다.

다음 현장/원본 대조 우선순위는 출발·도착 직선 연결, 터널 양단, 구월교 양단과 벤치 접속이다. 해당 지점의 최소 유효폭·턱높이·실제 종단경사·현재 통제는 이번에도 미측정이다. 보행 가능/휠체어 안전 등급을 새로 확정하지 않았다.

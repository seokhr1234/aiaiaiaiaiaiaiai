## 출처와 적용 기준

ZIP PRJ의 EPSG:5174를 확인해 EPSG:4326으로 표시하고 EPSG:32652에서 거리를 계산했다. HEIGHT의 수직 기준·노면 대응·현장 정확도는 미확인이다. 새로운 경사값을 경로 계산에 승격한 건수는 **0**이다. 기존 terrain-data와 경사 가중치는 유지한다.

[성북구 도서관 안내](https://www.sb.go.kr/children/contents.do?key=367)의 2025-12-26 수정 표는 일반 도서관 운영시간이다. 2026 무더위쉼터 운영 자료와 같은 개념으로 덮어쓰지 않는다. 월곡꿈그림 수요일 연장, 일부 도서관 월요일 휴관 규칙은 방문 전 재확인 근거로 표시한다. 글빛 주소와 해오름·장위행복누림·글빛 층수는 자료 간 차이가 있어 출입구·층위 확정에 사용하지 않는다.

[성북구의회 문서](https://www.sbc.go.kr/attach/record/SEONGBUK/appendix/a09/A0007166.pdf)는 공식 PDF의 웹 색인 표를 열람했으며 원본 다운로드에는 실패했다. 2026-05-29 신규 5개·해제 3개 쉼터 공지는 목록에서 확인했으나 상세 명단을 확보하지 못했다. 추측으로 지도에서 시설을 추가/삭제하지 않았다.

## 수집 제한과 재현

실행기의 서울시·Overpass·OSM HTTPS 요청은 CONNECT 단계 **403**이다. [실제 시도 기록](network-attempts.json). 정책을 우회하지 않고 사용 가능한 웹 커넥터로 공식 자료를 열람했다. 최신 쉼터 전체 API, 최근 OSM 변경분, 국토지리정보원 해당 지역 고해상도 원본은 미수집이다. 추가 인증·설정 질문은 하지 않았다.

```sh
python3 -m pip install -r donghaeng-nav/requirements-evidence.txt
python3 donghaeng-nav/scripts/collect-terrain-evidence.py --archive /path/to/oa22241-seq2.zip
python3 donghaeng-nav/scripts/enrich-rest-evidence.py
node donghaeng-nav/scripts/test-evidence.cjs
```

추출기는 원본을 수정하지 않는다. 셰이프 정점이 지정 bbox에 들어오는 피처를 선택하며, 영역 내 모든 등고선의 완전한 교차 클립을 보장하지 않는다. 연구용 GeoJSON은 원본 피처를 보존해 일부 선이 bbox 밖으로 이어질 수 있다. 앱은 별도의 graph hash가 맞는 근거 요약만 읽고 가중치에는 사용하지 않는다. 시설 보강은 이름이 일치하는 기존 공식 쉼터만 대상으로 한다. 모든 좌표·운영 원문·현장 확인 플래그와 자동 휴식 후보의 운영시간 판정을 보존하는 검사를 수행한다.

## GPS 개선

[gps-quality.js](../../../donghaeng-nav/dist/gps-quality.js)는 두 GPS 흐름에 공통 적용한다. 잘못된/중복/과거/미래 표본과 50m 초과 오차를 걸러내고, 갑작스러운 점프는 2초 이상·3회 일관된 표본을 확인한 후 재획득한다. 긴 수신 공백은 이전 필터 상태를 폐기한다. 독립 GPS의 자동 출발점 설정은 수신 오차 25m 이하에서만 한다.

표시는 정확도 가중 평활화를 적용하지만 경로 진행·이탈·도착 판단에는 통과한 **원래 좌표와 원래 accuracy**를 사용한다. 표시 원의 반경은 원래 오차에 이동 보정량을 더하며 정확도가 좋아졌다고 축소하지 않는다. 저품질 표본은 안내 진행과 도착 확인을 보류하고 마지막 안정 위치를 흐리게 표시한다. 화면 복귀/재탐색에는 이전 필터를 재사용하지 않는다. 위치 로그를 서버로 보내거나 저장하지 않는다.

[W3C Geolocation](https://www.w3.org/TR/geolocation/)의 고정밀 옵션은 요청 힌트다. 브라우저 코드로 GNSS 하드웨어 정밀도·실내 다중경로·지속적인 위치 편향을 없앨 수 없다. 모의 정지 잡음 RMS는 5.02m→2.12m, 일정 1.2m/s 보행의 표시 지연은 최대 1.49m였다. 실제 휴대폰 정확도 개선률이나 안전 검증이 아니다.

실기기 검증은 같은 보행 경로에서 정지·직진·회전·평행 도로·실내/실외 전환·수신 단절을 반복하고 알려진 기준점과 비교해야 한다. 실제 위치 기록은 사용자 동의 없이 수집하지 않는다.

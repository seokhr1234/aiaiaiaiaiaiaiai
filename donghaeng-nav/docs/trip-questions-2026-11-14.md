# 중앙 캐릭터가 순서대로 묻는 길 찾기

2026-11-14 KST. 사용자 요청: 길 찾기 페이지 진입 시 캐릭터를 중앙에 두고 질문을
하나씩 진행하도록 변경. 기존 지도/계산 엔진·이동 조건·서버 전용 키 처리는 유지한다.

## 동작

- 처음에는 동글이 1개를 중앙에 크게 표시하고 출발지만 묻는다.
- 출발지 → 목적지 → 몸 상태 → 이동 방법 순서의 4단계. 답하지 않은 상태에서는
  다음 단계로 넘어가지 않고, 검색어만 입력하고 장소를 선택하지 않은 경우도 막는다.
- 출발지는 GPS 또는 지도에서 선택한다. GPS 거부/실패 시 상태를 보여 주고 지도
  대안을 유지한다. 지도 선택 중에는 질문 화면을 비우고, 위치를 고르면 같은 질문으로
  돌아온다. 선택을 취소하고 질문으로 돌아갈 수도 있다.
- 이전/다음으로 돌아가도 기존 답을 보존한다. 마지막에는 출발·도착·상태를 요약해
  보여 주고 이동 방법을 고른 뒤에만 길 찾기를 실행한다. 교통 좌표 전송 안내는 유지한다.
- 별도 AI 버튼이나 접근성 체크박스는 추가하지 않았다. 원래 상태 해석·도보/교통
  계산 흐름을 그대로 사용한다. 입력 중 API를 자동 호출하지 않는다.
- 최종 제출 뒤 캐릭터와 원래 입력 form은 기존 헤더/지도 결과 화면으로 돌아간다.
  길 찾기 메뉴로 다시 들어가면 답을 유지한 채 질문을 다시 시작한다. 저장 메뉴도
  유지하며 ‘한 번에 입력’으로 기존 입력 화면을 사용할 수 있다.
- HTML의 기존 입력 요소를 이동해 사용하므로 중복 ID/복제 입력/별도 상태 저장소를
  만들지 않았다. 질문 제목의 읽기/초점 이동과 모션 줄이기 정책을 유지한다.

## 소스와 검증

`dist/trip-questions.js`와 `style.css`가 화면과 단계 상태를 담당한다.
`app.js`는 지점 선택 알림·질문 진입을 연결하고, `index.html`은 공통 스크립트를
읽는다. `server.mjs`의 정적 파일 허용 목록에 모듈을 추가했다. 원본 자료나 경로
가중치/GPS 엔진은 변경하지 않았다. 무결성 기록·공통 HTML5개·패키지 해시와 패치를 갱신한다.

`test-trip-questions-ui.mjs`/`--bundle`: 중앙 캐릭터1·위치 권한 거부·지도 선택/취소·
검색만 입력한 장소 거부·미완료 다음 제한·답 보존·마지막1회 제출·320px/가로/PC·
결과/저장 메뉴·기존 입력 전환 검사. 모의 교통이며 실제 업체 추가 호출0건이다.
`test-compact-ui.mjs`/`--bundle`는 ‘한 번에 입력’ 전환 뒤 기존 입력/결과 기능도 검사한다.
여정/시각 코어는 재검사했고 현장 검증이나 Vercel 배포를 새로 수행한 것은 아니다.

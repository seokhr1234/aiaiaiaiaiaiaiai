# 월곡역 최종 검증 · 2026-10-30

최종 진입점은 상위 폴더의 동행길-최종.html입니다. 동행길-시연.html도 같은 내용입니다. 개발 소스는 donghaeng-nav/dist이며 상위 dist는 과거 시안입니다. 외부 배포는 하지 않았습니다.

## 데이터

현재 17,484건을 중복 원본 ID 없이 읽습니다. 벤치 2,288, 의자 있는 정류장·시설 3,262, 쉼터 4,460, 엘리베이터 244, 에스컬레이터 56, 일반 계단 4,427, 단지 경계 2,745, 아파트 제보 구역 2입니다. 단지 경계와 제보 구역을 제외한 시설 기록은 14,737건입니다. 개별 의자 실물 수를 의미하지 않습니다.

작업 전 16,143건을 대조해 누락 및 원본 내용 변경이 없음을 확인했습니다. 수집 폴더에 추가된 공개공지 1,341건도 기존 통합 절차로 반영했습니다. HTML의 압축 데이터를 해제한 결과와 현재 원본 GeoJSON이 완전히 같습니다. 최종 파일은 약 11.1MB이며 지도·시설·도로 데이터를 손실 없이 내장합니다.

자동 휴식 후보는 월곡역 주변 182건입니다. 단지 내부·출입 제한·부지 대표 좌표·정밀도 불명 벤치 추정점은 후보에서 제외하지만 지도 자료에서는 삭제하지 않습니다. 좌표 없는 공식 에스컬레이터 CSV 1,882행에서 설비 마커를 만들지 않았습니다.

## 경로

월곡역 시연 기준점 → 월곡꿈그림도서관. 미검증 연결 거리를 포함한 추정값입니다. 실제 GPS 출발점에 따라 결과가 달라집니다.

| 조건 | 추정 거리 | 추정 보행 시간 | 휴식 |
|---|---:|---:|---|
| 거리 우선 | 351m | 6분 | 없음 |
| 무릎 통증·휴식 | 433m | 10분 | KB국민은행 앞 월곡역 승차대 의자 |
| 휠체어 | 383m | 7분 | 없음 |

휴식 시간 자체는 포함하지 않습니다. 휠체어·계단 회피 경로에서 등록 계단이 제외됨을 확인했습니다. 경사·보도 턱·폭·시설 가동 상태와 출입 동선은 별도 현장 확인이 필요합니다.

## 자동 확인

- 기존 경로 엔진, 자연어 부정 표현, 계단 제외, 경로 실패 처리
- 시설 원본 ID 중복 제거, 선형 분류, 좌표 없는 자료 제외, 출처와 위치 정밀도
- 서울 내장 배경 지도, 외부 타일 요청 없음
- 최종 HTML의 손실 없는 데이터 내장과 두 HTML의 동일성
- 별도 Chrome에서 로컬 HTML 실행, 세 가지 경로 비교, 순서 버튼, 출처 팝업
- 벤치 개별 표시와 전체 켜기/끄기, 표시 변경 전후 경로 동일
- 발표 모드, 상세 시뮬레이션, 저장과 다시 찾기, 목적지 검색
- 모바일 390px 가로 넘침 없음, GPS 권한 거부 시 안내
- 개발 서버의 실제 dist 화면에서도 433m 휴식 경로 계산, 브라우저 오류 없음

마지막 브라우저 검증 결과는 final-ui-results.json, 빌드 수량·SHA-256은 final-build.json, 화면은 final-desktop.png / final-mobile.png / final-mobile-facilities.png에 저장됩니다. 실제 현장 GPS 수신이나 시설의 현재 상태를 확인한 결과는 아닙니다.

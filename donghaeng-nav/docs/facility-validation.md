## 실제 브라우저 확인

정적 앱과 생성된 단일 HTML 양쪽에서 확인함.

- 초기 벤치 ON / 계단 OFF / 에스컬레이터 OFF.
- 계단 개별 ON: 선형 154개 + 아이콘 154개. 에스컬레이터 개별 ON: 선형 1개 + 아이콘 1개.
- 전체 OFF: 체크 해제와 시설 아이콘 0개. 전체 ON: 세 종류 모두 체크. 전체 등록/뷰포트 수는 표시 상태와 독립적으로 유지.
- 지도 이동/확대로 화면 내 개수 갱신. 한 화면에 모두 맞추면 벤치 전체 67 / 화면 67 등을 확인. 선이 화면을 통과하나 꼭짓점이 화면 밖인 경우는 단위 검사로 확인.
- 벤치/계단/에스컬레이터 팝업에서 종류·이름 미확인·원본 OSM 링크·2026-10-28T05:19:18Z·현장 미확인·이용 상태 미확인·OSM ID·ODbL 표시 확인.
- 벤치 묶음 40개를 누른 뒤 확대에 따라 32개 등 하위 묶음 및 개별 의자로 분리되는 것 확인.
- `/overlap/` 테스트에서만 같은 좌표로 만든 3개를 최대 확대(정적 타일 지도 최대 zoom 19)에서 펼쳐 개별 마커 3개와 원본 좌표/연결선 안내 팝업 확인. 실제 원본 파일은 변경하지 않음.
- 검색어 '카페'로 기존 장소 결과 확인. '중간에 쉬고 싶어요' 입력으로 958m/674m 비교 경로 확인. 시설 전체 ON/OFF 전후 조건 체크 값과 경로 텍스트 결과가 동일하고, OFF 상태 재계산도 동일함.
- `/failure/`: 두 GeoJSON 503 응답 → '수량 미확인'과 재시도 표시, 길 찾기는 정상.
- `/partial/`: 벤치 전용만 503 → 통합 파일로 벤치 67개와 나머지 시설 표시, 부분 오류 안내.
- `/empty/`: 빈 FeatureCollection 두 개 → 세 종류 0개, '등록된 시설이 없어요', 앱 정상 유지.
- 모바일 390×844: 컨트롤 기본 접힘, 가로 스크롤 폭 390으로 넘침 없음. 펼친 컨트롤 폭 244px. 전체 버튼과 범위 버튼 높이 44px. 모바일 개별 벤치 OFF/전체 OFF 시 시설 아이콘 제거 확인.
- 지도 출처/ODbL 고지 유지. 미등록 시설과 현장 접근성은 별도 미확인.

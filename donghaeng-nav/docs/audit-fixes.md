## 적용 범위

| 항목 | 변경과 확인 |
| --- | --- |
| A01 필수 휴식 재탐색 | `navigation-routing.js`에서 최초 후보와 같은 조건·건물 기하 적격 검사를 적용한다. 휴식 종류·첫 휴식 간격을 확인하고 충족 불가면 대체를 거절한다. `navigation-session.js`도 조건 변경·필수 휴식 누락을 독립적으로 거부해 기존 계획을 유지한다. 이미 휴식 완료한 경우만 경유를 생략한다. |
| A02 초기 준비 | 원본 9개 파일과 동일한 결정적 gzip 파일을 빌더가 생성한다. 필수 7개 자료는 병렬 준비하고 서울 배경은 대체 지도가 필요할 때, 추가 표고 근거는 부팅 후 읽는다. Node gzip·ETag/304도 지원한다. 필수 정밀·건물·지형 검증은 계속 부팅을 차단한다. |
| A03 기기 내 해석 | 내리막 회피를 포함하고 `계단이 힘들지 않아요`, `휠체어를 쓰지 않습니다`, `쉬운 길`의 오해를 수정했다. 같은 문장의 별도 긍정 조건을 유지한다. |
| A04 쉼터 운영 | 실제 탐색한 첫 경유 거리와 보행속도로 도착 예상 시각을 계산한다. 출발점→도로 연결 시간도 포함하며 도착 전에 닫는 쉼터는 제외한다. 운영시간 미확인·공식 충돌은 계속 제외한다. |
| A05 작은 화면 팝업 | 화면 폭에 맞추고 지도 상단 조작부·하단 패널·출처 영역을 피해서 위치와 스크롤 높이를 조정한다. 모바일 출처 목록은 스크롤할 수 있으며 원본 링크를 유지한다. 320px에서 닫기 버튼을 실제 클릭할 수 있다. |
| A06 저장 자료 | 새 `saved-data.js`가 배열과 항목 형식을 검사한다. 유효 항목을 표시하고 읽을 수 없는 항목 수와 복구 버튼을 제공한다. 읽기만으로 저장 원문을 덮어쓰지 않는다. |
| A07 목적지 연결 | 검색·빠른 선택·시설 선택에 같은 건물 연결 사전 검토를 적용한다. 도서관·정류장 기준점의 겹침을 알리고 지도에서 진입 위치를 지정하게 한다. 검토용 경로는 명시적 선택으로 열며 실제 GPS 안내는 계속 차단한다. 자동으로 출입구를 만들어 좌표를 바꾸지 않는다. |
| A08 팝업 가독성 | 시설 설명·근거 일반 글자를 13px로 키우고 어두운 색으로 조정했다. 일반 텍스트 대비 4.5:1 이상을 확인하고 운영시간 충돌 경고를 유지했다. |
| A09 키보드 초점 | 대안을 선택해 카드를 다시 그린 뒤 해당 선택 버튼에 초점을 복원한다. Enter 선택 후 `aria-pressed=true`인 버튼이 활성 초점이다. |

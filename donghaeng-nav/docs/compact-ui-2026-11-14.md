# 간단한 화면과 안내 캐릭터

2026-11-14 KST. 사용자 최신 요청에 따라 반복 문구를 줄이고 UI를 간소화했다.
앞선 ‘전역 UI는 마지막’ 계획보다 이번 명시적인 UI 변경 요청을 우선했다.

- 입력은 이동 방법·출발·목적지·몸 상태·길 찾기를 중심으로 구성했다.
  출발 설정은 모바일/PC 모두 기본으로 접고, 상태 예시·AI 처리/개인정보는
  ‘도움말·개인정보’, 비교 시연/발표 모드는 ‘서비스 정보’에 모았다.
- 대중교통은 짧은 후보 요약과 ‘접근성·환승 시각 미확인’을 표시한다. 승하차 순서,
  업체/조회 정보·도보 계산/출처는 필요할 때 펼친다. 좌표 전송 안내는 유지한다.
- 이동 순서는 현재 단계와 이전/다음/재생 중심으로 줄였다. 재생 중에는 재생 버튼을
  일시정지로 교체하고 종료를 제공한다. 전체 목록과 미확인 항목은 접을 수 있다.
  미확인·위험을 확인 완료로 바꾸지 않았으며 GPS/AI 적격 제한을 유지한다.
- 지도 위 중복 배지/범례를 줄이고 정밀 자료 조작을 ‘지도 정보’로 짧게 표시했다.
  지도 출처/저작권은 삭제하지 않고 스크롤 가능한 작은 영역에 유지한다.
- 캐릭터 ‘동글이’ 1개를 헤더에 추가했다. 초록색 새싹과 작은 가방을 가진 안내
  캐릭터로, 외부 이미지 없이 공통 HTML의 SVG로 그렸다. 화면 읽기 이름을 제공하고
  짧은 손인사/눈깜박임은 2회만 재생하며 모션 줄이기 설정에서는 끈다.
- 기존 경로 엔진·이동 조건·키 처리·시설 토글·GPS와 연구/원본 자료를 보존했다.
  소스·무결성 기록과 공통 HTML5개·빌드/패키지 해시·변경 패치를 함께 갱신한다.

변경 소스: `dist/index.html`, `style.css`, `transit.css`, `app.js`, `transit-ui.js`,
`transit-walk-review.js`, `journey-review.js`, `precision-map.js`.

검사: 새 `test-compact-ui.mjs` 및 `--bundle`에서 메인/단일 HTML의 320/393px·가로·
PC·모션 줄이기·캐릭터1개·입력/상세 펼치기·교통 후보/도보·이동 순서·재생/취소·
후보 캐시·조건 변경 정리를 확인했다. `test-transit-walk-review-ui.mjs`는 변경된 짧은
버튼 이름과 상세보기 구조에 맞춰 갱신했다. 시각/여정·대중교통 코어 및 GPS 코어도
검사했다. 교통은 모의 응답이고 도보는 기존 서울 도로망이며 실제 업체 추가 호출0건이다.

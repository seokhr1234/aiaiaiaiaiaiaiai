# 휠체어 경사 회피 수정 · 2026-10-31

기존 휠체어 계산은 경사에 `1 + 경사 × 0.28` 비용만 더했습니다. 거리 절약에 밀려 참고 추정 8.43% 구간이 포함될 수 있었으므로, 종전 검증의 등록 계단 0구간만으로 경사 회피까지 정상이라고 결론 내릴 수 없습니다.

## 변경

- 엔진에서 휠체어 조건을 강제합니다. 계단 제외·경사 회피를 켜고 거리 우선을 끕니다. AI·저장값이 잘못된 플래그를 줘도 동일하게 적용합니다.
- 휠체어는 OSM 등록/기존 유효 Tilezen 참고 추정 5% 초과를 추천에서 제외합니다. 사용자가 더 엄격한 수치를 입력하면 그 값을 유지합니다. **5%는 제품의 회피 정책값이며 통행 안전 기준이나 노면 경사 보장이 아닙니다.**
- 허용된 경사에서도 비용을 제곱으로 늘리고(`1 + 경사² × 0.8`), 경사 미확인 구간은 최소 10배 부담을 적용합니다. 기존 불확실성 비용이 더 크면 유지합니다. 미확인을 평지로 취급하지 않습니다.
- 벤치 경유 전후 구간에도 같은 규칙을 적용합니다. 경로가 없으면 조건을 풀지 않고 안내를 중단합니다.
- 휠체어 화면에 제약 없는 일반 최단 경로 선택 카드를 내보내지 않습니다. 결과는 ‘경사 회피 우회 후보 · 통행 미확인’으로 표시합니다.

학교 앞 **버스 정류장**까지 휠체어, 휴식 미요청의 같은 출발·도착 비교:

| 유효 등록·참고 추정 5% 초과 길이 | 약 43m | 0m |

실제 Gemini 상태 해석 후 벤치 휴식을 포함한 Chrome 실행은 약 912m, 등록 계단 0구간, 참고 추정 최대 4.49%, 경사 미확인 약 260m입니다. 휴식 장소도 새 우회 경로에서 다시 선정됩니다. 학교 건물 대표점까지는 별도로 약 1,131m(휴식 포함 약 1,180m)이며 마지막 연결은 미검증입니다.

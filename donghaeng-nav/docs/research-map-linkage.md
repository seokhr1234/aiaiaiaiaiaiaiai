# 공식 조사 근거의 지도 연결 — 2026-11-05 KST

round4 조사 커밋 `3240968`에서 확보·검증한 공개 자료 중 기존 시설과 일대일 대응이 확인된 근거를 지도에 연결했다. 원문은 기존 research에 그대로 보존한다. 이번 적용을 현장 확인이나 안전 검증으로 표시하지 않는다.

## 적용 범위

- 서울시 공개 전체 CSV의 4,092개 쉼터를 이름·주소·경위도로 대응시키고 23개 공식 필드 일치를 확인한 뒤, 기존 시설에 `official_recheck`를 추가했다. 팝업에 **공식 자료 수집일 2026-11-05**, **2026년 시설 등록 / 자료 갱신일 2026-11-05**를 표시한다. 기존 10월 28일 수집 기록과 현장 미확인 표시는 보존했다.
- 성북구 공지에서 시설명과 도로명주소를 대조한 보문느티나무경로당·동일하이빌뉴시티경로당·성북문화예술교육센터 3곳에 공지 원문 링크·기준일·수집일·운영 안내를 추가했다.
- 동일하이빌뉴시티경로당과 성북문화예술교육센터는 공지/CSV 운영 안내가 달라 경고를 표시하고 자동 휴식 후보에서 제외했다. 전자는 기존에도 회원이용시설로 제외됐으므로, 기존 자동 후보 중 실제로 새로 보류된 시설은 성북문화예술교육센터 1곳이다. 공식 운영시간 원문과 시설 좌표는 수정하지 않았다. 지도에서 찾아 근거를 확인하거나 직접 목적지로 선택하는 것은 가능하다.
- 모바일에서 시설을 열면 하단 입력창을 접고 팝업 표시 여유를 확보한다. 경고는 팝업 상단에 표시하고 긴 시설명은 줄바꿈한다.

## 적용하지 않은 항목

신규 지정/해제 공지 중 시설 동일성이 확인되지 않은 항목은 추가·삭제하지 않았다. 주소나 정류장 ID를 임의 좌표로 바꾸지 않았다. 복합센터와 도서관을 같은 시설로 취급하지 않았다.

최신 OSM의 노드열 변경 5개 도로와 나머지 변경 객체는 기존 그래프/표고 연결을 검증하기 전까지 런타임에 적용하지 않았다. 이미 연결된 서울 표고점 944개·등고선 191개의 구간별 참고 근거는 그대로 유지한다. 두 ZIP의 밀도 차이를 정밀도 향상으로 해석하거나 노면 경사를 계산하지 않았다. **새 좌표 0개, 새 경사 승격 0건, 현장 검증 false**다.

## 재현과 검증

```sh
python3 donghaeng-nav/scripts/link-official-research.py
node donghaeng-nav/scripts/test-research-map-linkage.cjs

```

수집 스크립트는 CSV 및 공지 HTML/이미지의 응답 상태·SHA-256·크기를 확인하고, 빈 자료·중복·공식 필드 불일치·시설명/주소 불일치가 있으면 런타임을 쓰기 전에 중단한다. 동일 조사 근거를 중복 추가하지 않도록 배치 ID로 대체한다.

검증 결과는 [자료 적용 기록](research-map-linkage-data.json), [단위·정책 검사](research-map-linkage-results.json), [모바일·단일 HTML·빈/잘못된 자료 검사](research-map-linkage-ui-results.json)에 있다. 기존 메인 브라우저 8개 묶음, 내비게이션 코어 24개 묶음과 실제 내장 도로망 4사례도 확인한다. 실제 Gemini 호출·휴대폰 GPS·현장 통행 검증은 수행하지 않는다.

최종 [빌드·보존 검증](research-map-linkage-build-results.json) 통과: 런타임 자료 9개·보호 코드 15개 해시, HTML 5개 동일성, 전달/패키지 해시, 기존 research 불변을 확인했다. 새 UI 검사 4개 묶음과 메인 브라우저 검사에서 오류 0건이다.

기존 연구 파일과 런타임의 다른 8개 데이터셋 및 기존 보호 코드 13개는 보존했다. 시설 메타데이터의 해시만 검증 결과에 따라 갱신하고, 시설 표시/휴식 후보 코드 2개를 보호 목록에 추가했다. 빌드는 무결성 검사를 유지하며 HTML 5개·manifest·전달/패키지 해시를 갱신한다. 이전 round4 보존 검사는 당시의 앱 불변 검증이며, 이번 적용 이후의 상태는 이 문서와 새 검사 결과를 기준으로 한다.

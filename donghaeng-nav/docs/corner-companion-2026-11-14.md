# 손가락 표현 제거·우측 하단 말풍선

2026-11-14 KST. 사용자 요청에 따라 캐릭터 손가락 표현과 중앙 질문 화면을 바꿨다.

- 손가락 선과 손을 든 그룹을 삭제했다. 양쪽 팔이 아래로 둥글게 내려온 SVG로
  바꿨으며 손인사 애니메이션도 제거했다. 캐릭터는 복제하지 않고 기존 1개를 사용한다.
- 출발·목적지·몸 상태·이동 방법의 질문을 우측 하단 말풍선으로 옮겼다. 지도가
  보이며 말풍선 바깥은 지도 조작이 가능하다. 모바일은 하단 메뉴와 안전 영역 위에
  두고 작은/가로 화면에서는 말풍선 내부를 스크롤한다.
- ‘−’나 캐릭터를 눌러 말풍선을 접고 다시 열 수 있다. 단계와 입력은 유지된다.
  다음 단계로 이동하면 말풍선 스크롤을 위로 돌려 질문을 볼 수 있게 했다.
- 지도에서 선택하기·선택 취소·GPS 거부 안내·이전/다음·최종 검색·저장 메뉴와
  ‘한 번에 입력’ 전환을 유지한다. 지도 크기는 패널 전환 후 다시 계산한다.
- 지도 출처는 말풍선/캐릭터와 겹치지 않도록 왼쪽 아래에 둔다. 출처/미확인/위험
  표시와 API 키 처리, 경로/GPS 엔진·원본 자료는 바꾸지 않는다.

변경 소스: `dist/index.html`, `style.css`, `trip-questions.js`, `app.js`.
검증 후 무결성 기록과 공통 HTML5개·빌드/전달/패키지 해시·변경 패치를 갱신한다.

`test-trip-questions-ui.mjs`/`--bundle`은 손가락 그룹 없음·둥근 팔·우측 하단 위치·
지도 표시·접기/재열기·입력 보존·GPS 거부/지도 선택·최종1회 제출·320/393px/가로/PC·
기존 입력/저장 전환을 검사한다. `test-compact-ui.mjs`는 기존 입력/결과 동작과 모션
줄이기를 검사했다. 거리 제한 코어도 재검사했다. 교통은 모의 응답이며 실제 업체
추가 호출0건이다. 현장/실기기 GPS나 배포를 새로 검증한 것은 아니다.

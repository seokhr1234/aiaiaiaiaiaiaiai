# 출발지 이름·주소 검색

2026-11-14 KST. 사용자 요청에 따라 출발지도 목적지처럼 검색할 수 있게 했다.

- 출발 질문의 GPS/지도 선택 위에 이름·주소 검색창을 추가했다. 목적지와 같은
  기존 서울 등록 장소 목록을 조회하며 외부 검색 API는 호출하지 않는다.
- 두 글자 이상 입력하면 이름/주소에서 최대10개를 표시한다. 결과를 선택하면
  출발 좌표·이름·지도 핀·검색창이 함께 바뀌고 다음 단계로 진행할 수 있다.
- 검색어를 수정하거나 지우면 이전 출발 좌표/핀을 해제하고 진행 중 분석/경로를
  무효화한다. 글자만 입력한 상태나 결과 없음으로는 다음/검색을 실행하지 않는다.
  이미 선택한 목적지는 유지한다.
- 아래 화살표로 첫 결과에 초점을 주고 Enter로 선택할 수 있다. Escape는 결과를
  접는다. 장소 이름·주소는 HTML이 아닌 텍스트로 표시한다.
- 지도/GPS로 출발지를 바꿔도 검색창을 동기화한다. 독립 GPS 표시와 검색한 출발
  선택을 구분하며 검색 중 대기 GPS가 출발지를 덮지 않도록 한다.
- 말풍선/기존 입력 화면·320/393px·가로/PC를 지원한다. 화면 전환 후에도 현재
  출발 질문의 검색창이 접히지 않도록 모바일 레이아웃 연결을 보완했다.

검색 범위는 기존 등록 장소의 이름과 주소다. 일반 도로명/지번 주소 전체를 좌표로
변환하는 새 지오코더를 연결한 것은 아니다. 결과가 없으면 지도나 GPS로 선택할 수
있으며 등록 시설의 대표점을 검증된 출입구로 바꾸어 표시하지 않는다.

변경: `dist/index.html`, `app.js`, `trip-questions.js`, `style.css`, 빌드/무결성 기록과
공통HTML5개·전달/패키지 해시. 기존 원본9개/gzip9개·연구와 경로/GPS 엔진은 유지한다.

문자열 HTML 미실행·GPS/지도 동기화·작은/가로/PC·기존 입력 전환을 검사했다.

# 2026-11-04 이용안내 개편

사용자가 긴 문단의 이용안내를 읽기 어렵다고 지적해, 승인한 구성으로 화면을 개편했다.

## 화면 구성

- 첫 화면: 출발지·목적지 선택 → 내 상태 입력 → 길 찾기의 세 단계 카드.
- 필수 확인: 월곡역 주변 길 찾기 범위와 턱·폭·경사·출입구·시설 상태의 현장 확인 필요성을 펼치지 않아도 표시.
- 추가 설명: 현재 위치, GPS/재생 차이, AI 전송 정보, 경로/제보 저장, 자료 출처·한계의 다섯 항목을 기본 접힘으로 제공. 다시 열면 접힌 상태와 맨 위 위치로 복원.
- 행동 연결: 하단 시작 버튼을 스크롤 영역과 분리하고 목적지 입력으로 이동. 저장 화면에서 열어도 입력 화면으로 전환.
- 읽기·접근성: 본문 16px, 줄 간격 1.65, 번호·짧은 제목, 모달 이름, 제목으로 초기 포커스, 기본 dialog/details의 키보드·Esc 조작, 44px 이상 조작 영역.
- 개인정보: HTTP(S) 서버 연결, 일반 파일의 기기 내 해석, PortableAI가 있는 파일의 직접 Gemini 연결을 구분. 지도 타일 요청과 AI 요청도 구분하며 내장 정밀지도 주의 문구는 해당 데이터가 있는 버전에 표시.

## 반영 범위와 재현

실제 소스 `donghaeng-nav/dist/index.html`, `style.css`, `app.js`와 최상위 HTML 5개, 실행 패키지의 HTML 2개에 반영했다. 경사 근거 등을 표시하는 기존 공용 info 팝업은 보존했다.

`python donghaeng-nav/scripts/sync-usage-guide.py`는 분리 소스의 안내 마크업·CSS·이벤트 코드만 기존 HTML들에 동기화한다. 같은 명령을 반복해도 결과가 같아야 한다. 일반 전체 빌드는 기존 `build-html.py`를 사용하며, 새 안내는 분리 소스에 포함되어 있다.

이 환경에는 전체 빌드에 필요한 원본 지형 타일·시설 전처리 입력이 없어 전체 GIS/시설 재생성을 실행하지 않았다. 동기화 도구는 기존 각 HTML의 정밀지도·GPS·PortableAI 차이와 내장 데이터를 유지한다. 분리 소스와 별도 HTML의 기존 버전 차이를 해소한 작업은 아니다. 기존 지형 해시 검증을 우회하거나 지도·경로 엔진을 교체하지 않았다.

기본 HTML 3종의 새 SHA-256/크기를 `final-build.json`과 `전달-검증.json`에 반영했다. 기존 검증 필드와 패키지 `검증결과.json`은 과거 검사 기록이며, 이번 검사 결과로 덮어쓰지 않았다. 패키지 README에 갱신 범위를 추가하고 SHA256SUMS는 현재 파일에 맞췄다.

## 검사 결과 — 통과

실제 Chromium과 Playwright 검사에서 브라우저 스크립트 오류 0건을 확인했다. 동기화 반복 결과 불변, 패키지 해시 4개 일치, 공백 검사도 통과했다. 외부 HTTPS 요청은 차단했다. 실제 Gemini 키·요청이나 현장 GPS는 사용하지 않았다.

- Node `/app/`와 `/`: 새 안내의 표시, 서버 실행 시 개인정보 문구 확인.
- 데스크톱: 세 단계·기본 접힘·질문 펼치기, Tab/Space/Esc, 배경 조작 요소로 포커스가 이동하지 않음과 닫기 후 복귀 확인.
- 모바일: 실제 메뉴 진입, 320×568·393×852·667×375에서 가로 넘침 없음, 질문을 모두 펼쳐도 시작 버튼 유지, 재개방 시 초기화, 목적지 입력 포커스 확인.
- 경로 화면: 저장 화면에서 시작 버튼으로 입력 복귀, 목적지 미선택 처리, AI 키 없는 서버의 기기 내 대체 해석과 경로 계산, 기존 공용 정보 팝업 확인.
- 별도 HTML 7개: localhost에서 각각 실행·초기화·안내 열기·목적지 입력 이동, 서버 개인정보 문구와 정밀지도 안내 조건 확인.
- 파일 실행 설명: `file:`/`content:`와 PortableAI 유무에 따른 안내 문구는 격리 JavaScript에서 분기 확인. 관리형 Chromium이 file URL을 차단하므로 브라우저의 실제 파일 열기는 확인하지 못했다.
- 정적 보존: HTML 7개의 인라인 실행 JavaScript 124블록 구문 검사, 내장 gzip-base64 JSON 47블록의 원본 일치, 안내 외 스크립트 본문의 일치 확인. 경로 엔진·지도·지형 및 기존 research 자료 불변 확인.

화면: [모바일](usage-guide-mobile.png), [데스크톱](usage-guide-desktop.png).

실제 휴대폰·사용자 키 Gemini·위치 권한/현장 통행·온라인 타일 연결 검증은 이번 이용안내 변경의 검사 범위에 포함되지 않는다.

## 게시 요청: Vercel 배포 생략

사용자가 커밋·푸시만 요청해 이번 커밋에 `[skip vercel]` 표시를 넣고, 최상위 `vercel.json`의 `ignoreCommand`로 표시가 있는 커밋의 Vercel 빌드를 생략한다. 표시 없는 후속 커밋은 이 규칙으로 차단하지 않는다. Vercel CLI나 수동 배포 훅은 실행하지 않는다. [공식 종료 코드 규칙](https://vercel.com/docs/project-configuration/vercel-json#ignorecommand)에 따라 일치 시 0(생략), 불일치 시 1(진행)이다.

# 시설·지도 통합 패널과 경사 표시

요청: 왼쪽 위 시설/지도 정보 UI를 합치고 서울 경사도를 볼 수 있게 추가.

`시설·지도` 하나의 버튼에서 시설 / 경사 / 지도 자료 탭으로 전환한다. 기존 시설 검색·종류별 표시와 정밀 검토 자료/파일 입력은 원래 DOM 및 처리기를 유지한다. 패널을 열면 우측 하단 질문 말풍선은 접히며 입력은 보존된다.

경사 탭은 서울 등록 경사와 월곡 추정 경사를 각각 켜고 끈다. 0–3%, 3–6%, 6–10%, 10% 이상과 수치 미확인을 구분한다. 이는 통행 가능/안전 등급이 아니다. 선을 누르면 원문 경사 태그/OSM way와 출처 또는 지형 추정임을 확인할 수 있다. 서울 전체 보기/월곡 범위 보기 버튼을 제공한다.

## 자료와 범위

- 서울: 기존 city-walk 원본 그래프의 연결선과 OSM incline 태그를 그대로 추출한 3,921구간. 명시적 % 또는 각도 단위가 있는 수치 312구간만 색으로 표시하며 up/down/단위 없는 값은 회색 수치 미확인으로 표시한다. 원본 경로 엔진의 단위 해석을 수정하지 않았다.
- OSM/Geofabrik 2026-11-09T21:22:17Z 기준, 2026-11-11 수집. 2026-11-15는 화면 기능 작성일이다. [incline 태그 원문 정의](https://wiki.openstreetmap.org/wiki/Key:incline). 원본 두 압축 파일과 해제 파일 SHA-256을 manifest에 대조한 뒤 원본 좌표만 추출한다.
- 월곡: 이미 로드된 graph의 적용 가능한 terrainSlope만 표시한다. Tilezen 지형, 2026-10-31 수집. 교량·터널·계단·층위/엔진이 보류한 추정은 새로 채우지 않는다. 화면 범위와 확대 수준 15 이상에서만 렌더링한다.
- 서울 전역을 빈틈없이 덮는 실측 경사도/지형 히트맵이 아니다. 선이 없는 길은 경사 미확인이다. 결측을 0%로 바꾸지 않으며 추가 경사값을 경로/GPS 입력으로 승격하지 않는다.

원본 런타임 자료 9개, 기존 도시 그래프와 연구 자료는 바이트 그대로 보존한다. 표시용 파생 GeoJSON 두 파일은 별도 `slope_assets` 해시 그룹으로 등록하고 단일 HTML에는 압축 내장한다. API/새 키/외부 지형 요청은 필요 없다. 파일 실행 시에도 경사 자료를 표시한다.

추가: `dist/map-layers.js`, 표시용 registered-slopes.geojson 및 gzip, 재생성 스크립트 `scripts/prepare-slope-overlay.py`, UI/출처 검증. 수정: app.js/index.html/style.css/trip-questions.js/server.mjs/build-html.py, 무결성 기록, README, 수정이력, HTML 5개/패키지 체크섬/전달 검증.

검증: 출처 해시와 원본 연결선 보존, 통합 패널 한 개, 시설·지도 자료 탭 유지, 표시 켜기/끄기, 로딩 실패 후 재시도, 경로 그래프/조건/출발 입력/시설 상태 보존, 320px/393px/가로/데스크톱, 말풍선 복귀, 소스 및 단일 HTML. 실제 업체 API 호출 0회. 브라우저 외부 요청은 차단해 내장 지도 폴백에서 검사했다. 새 지형 실측/현장 접근성·실기기 GPS/운영 배포는 검사하지 않았다.

상세 결과: `slope-source-results.json`, `map-layers-ui-results.json`, `map-layers-bundle-ui-results.json`, `map-layers-release-integrity.json`. 이전 기능의 결과 기록은 당시 검사 결과로 보존한다. 이번 변경은 미커밋·미푸시·미배포.

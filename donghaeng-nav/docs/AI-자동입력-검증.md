# 상태 문장만으로 길 찾기 · 2026-10-31

- 경로 조건 체크박스, AI 활성화 체크박스, 별도 해석 버튼, 휴식 장소 선택창을 제거했습니다. 상태 문장과 목적지를 입력하고 길 찾기 한 번으로 AI 해석→실제 도로망 경로 계산을 수행합니다.
- AI가 추출한 조건과 추천 이유는 결과에서 읽기 전용으로 표시합니다. 휠체어는 등록 계단을 제외하고 기존 경사 부담 회피 가중치를 적용합니다. 경사 미확인·구조물·자료 차이 안내는 유지합니다.
- 지도 시설 ON/OFF는 표시만 바꾸며 경로 조건에 영향을 주지 않습니다.
- 입력 수정 시 진행 중 AI 응답을 취소·무시합니다. 성공한 해석만 재사용하고 실패 후에는 같은 문장으로도 AI를 재시도합니다. 저장한 경로도 원래 상태 문장에서 다시 해석합니다.
- 파일 단독 실행 또는 연결 오류는 기기 내 규칙 해석이라고 명시합니다. AI 성공으로 표시하지 않습니다.

## 실제 제공자 확인

기존 `gemini-2.5-flash-lite` 생성 요청은 404(신규 사용자 이용 불가)를 반환했습니다. 제공자가 안내한 `gemini-3.5-flash-lite`의 실제 생성 성공을 확인하고 기본값과 현재 Downloads 설정의 모델만 변경했습니다. 키는 변경하거나 결과물에 포함하지 않았습니다.

실제 로컬 서버의 Chrome에서 휠체어·오르막 회피·벤치 휴식 상태를 입력해 Gemini 해석→월곡역에서 서울사대부설중학교 **버스 정류장**까지 약 793m 경로를 확인했습니다. 등록 계단 0구간, 의자 휴식 지점이 반영됐습니다. 학교 건물 출입구까지의 통행 검증을 뜻하지 않습니다. AI에는 상태 문장만 전송됐습니다. 자세한 결과: `ai-only-live-results.json`.

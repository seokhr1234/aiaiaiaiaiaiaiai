# 정류장 제외 실제 벤치 추가 · 2026-10-29

벌집어린이공원 곡선형 고정 벤치와 햇살어린이공원 운동기구 옆 등받이 벤치를 사진에서 개별 식별해 1개씩 추가했다. 벤치 등록 객체 2,220→2,222; 정류장 추가 0. 공원 대표 위치를 개별 벤치로 재분류하지 않았다. 2026-06-25 로드뷰 원본과 두 촬영 방향을 보존했다. 개별 위치는 약30m 오차가 있는 사진 해석 추정치이며 실측·사진측량 위치가 아니다. 지도 팝업에 정확도와 현재 상태 미확인을 표시한다.

6개 공원 12개 지상 촬영 방향을 대조했고 명확히 식별된 두 벤치만 추가했다. 기존 OSM 벤치 30m 내 중복이 없는지 검사한다. 반복 병합 시 같은 GeoJSON이 생성된다. 시설 검사·배경 검사·JS 문법 검사 통과.

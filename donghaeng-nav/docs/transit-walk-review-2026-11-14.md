# 대중교통 후보의 서울 도보 구간 참고 계산

구현·검사: 2026-11-14 KST. 기준 커밋 `7fa090a`.
[후속 계획](transit-next-plan-2026-11-14.md)의 **T4 일부**를 진행했다.
사용자가 고정 IP/ODsay 설정을 준비하는 동안 인증에 의존하지 않는 작업이다.
실제 ODsay 검색·노선 기하·출입구 ID 대응을 완료한 것으로 표시하지 않는다.

## 사용자 동작

메인 또는 확장 화면에서 대중교통 참고 후보를 받은 뒤 **도보 구간 참고 계산**을
누른다. 출발지→첫 승차 참고점, 환승 참고점 사이, 마지막 하차 참고점→목적지를
원래 이동 조건으로 서울 OSM 등록 도로에서 계산한다. ODsay를 다시 호출하지 않는다.

업체 도보 시간과 등록 도로의 거리/시간, 핀과 등록 도로 사이의 미검증 간격,
경사 미등록 길이와 자료 출처를 구분한다. 지도 점선은 계산한 도로 노드만 연결하며
핀까지의 빈 구간과 버스·지하철 노선을 직선으로 채우지 않는다.

후보를 바꾸면 이전 도보 선을 지우고 같은 조회의 계산 결과는 메모리에서 복구한다.
조건/출발/도착/모드 변경은 취소·캐시/지도 지우기를 수행한다. 취소 뒤 늦은 응답이
결과를 되살리지 못한다. 새 페이지 이동 없이 메인과 확장에서 같은 표시 모듈을 쓴다.

## 계산과 검증의 구분

- **업체 참고 위치:** 요청은 클라이언트의 후보 좌표를 받아 보행 계산만 한다.
  서버가 업체 응답을 인증하거나 실제 정류장/출입구에 대응했다는 뜻이 아니다.
- **계산한 등록 도로:** 기존 서울 망의 원본 노드/선분을 사용하며 계단 회피·명시
  경사 상한 등 같은 조건을 유지한다. 실제 보도 편·턱/폭·출입·운영 상태는 미확인이다.
- **역내 환승:** 지하철을 포함한 환승은 출입구·층위·역내 접속 근거가 없어 계산을
  보류한다. 도로 우회로 역내 환승을 대체하지 않는다.
- **같은 표시 좌표:** 연결·환승 시간0으로 바꾸지 않고 미확인으로 남긴다.
- **조건·자료 부족:** 휴식·경사 회피·휠체어 조건의 근거가 없거나 등록 도로가
  끊겼으면 구간별 이유를 표시한다. 조건을 완화하거나 직선 대안을 만들지 않는다.
- **시간:** 모든 도보 계산이 있어도 등록 도로 부분의 시간 합만 제공한다. 핀/출입구
  접속·역내 이동·대기·운행편 재계산이 없어 전체 여정/도착 시각은 미확인이다.

모든 응답은 `review_only`, `stopMappingVerified:false`, `timetableVerified:false`,
`accessibilityVerified:false`, `restVerified:false`, `fieldVerified:false`다.
GPS 안내·접근성 충족·AI 추천 적격 후보로 승격하지 않는다.

## API와 자원 제한

`POST /api/transit/walk-review`는 Node와 Vercel에 직접 연결돼 키·별도 자료 서버가
필요 없다. `/api/index?route=transit/walk-review` 재작성 경로도 검사했다.
본문은 `origin`, `destination`, `profile`, `atTime`, `candidate`만 받으며
`candidate`는 후보 ID와 구간별 ID/종류/시작·끝 좌표/업체 분만 포함한다.
임의 URL·키·검증 완료 주장·정류장 이름을 전송할 필요가 없다.

- JSON 최대32KiB, 입력20구간·승차6구간·도보 계산7구간까지.
- 요청당 전체 계산12초, 각 도로 탐색 최대8초/남은 시간 중 짧은 값.
- 인스턴스당 검토1개. 기존 단독 서울 도보 요청의 동시2 제한은 유지된다.
  두 API를 합친 계정 전체 제한이나 운영 SLO를 구현한 것은 아니다.
- 도형은 구간당4,000점·전체12,000점 이하. 초과·시간 한도는 미확인 구간으로 남긴다.
- 원래 JSON/출처·버전·원본 노드/선분과 미검증 접속 간격을 보존한다.
- 브라우저 출처/메서드/입력·조건/시각·취소를 검사하고 임의 예외 원문은 내보내지 않는다.

새 자료 수집은 없다. 원래 서울 망의 **자료 기준2026-11-09T21:22:17Z**,
**수집2026-11-11**, EPSG:4326/ODbL-1.0을 유지한다.
11월14일은 구현/계산 검사일이며 보도 실측일·자료 갱신 기준일이 아니다.

ODsay 인증 성공으로 해석하지 않는다. 공개 고정 좌표 예의 등록 도로3개는
약973m/15분, 964m/15분, 1,493m/23분이었다. 미검증 접속과 대기 시간은 이 수치에
포함되지 않는다. 원문 업체 도보 시간과 달라도 운행편/막차 가능 여부는 확정하지 않는다.

거부, 시간/도형/동시 제한, 취소·늦은 응답, 320/393px·가로·후보 전환과 기존 도보/API
회귀가 포함된다. 실제 외부 업체 호출은0건이다. [데스크톱](transit-walk-review-desktop.png),
[모바일](transit-walk-review-mobile.png)은 모의 후보·실제 등록 도로의 화면이다.

T4 출입구/정류장 ID·방향·층위 대응, T5 시간표·전체 여정 재계산, T6 실시간 접근성·
반복 휴식, 이후 운영/정밀자료·현장 검증은 남아 있다. 고정 IP와 Server 키가 준비되면

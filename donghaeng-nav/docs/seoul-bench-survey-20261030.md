# 서울 벤치 추가 반영 · 2026-10-30

이번 조사에서 사진 확인 벤치 39개(카카오 거리사진 11개, Mapillary 28개)와 공식 벤치 설치 지점 16곳을 지도와 시연 HTML에 추가했다. 등록 건수 2,233→2,288. 공식 설치 지점에는 여러 벤치가 있을 수 있어 개별 의자 개수와 동일하지 않다.

Mapillary는 서울 경계와 겹치는 공개 지도 타일 214개를 전부 조회했고 오류 0건, 원본 벤치 객체 258건을 확보했다. 도로 거리·정류장 인접·중복 가능성·관측 시점으로 169건을 보류했다. 남은 89건의 사진을 모두 대조했고 28건만 추가했다. 자세한 원본과 개별 판정은 data/accessibility/seoul/mapillary-benches/에 있다.

기존 거리 사진 278장의 자동 후보 123건을 직접 대조해 11개 벤치를 확인했다. 같은 사진을 일반 카메라 시야로 보정해 후보 83건을 한 번 더 검토했으나 중복·오인식·불명확으로 추가 등록은 없었다. 자동 후보를 지도에 무조건 넣지 않았다.

위치는 모두 현장 실측이 아니다. 카카오 사진 벤치는 약 30m 이상 오차가 가능한 추정 위치이고, Mapillary는 여러 사진으로 계산한 제공처의 추정 위치로 물리적 정확도는 미상이다. 사진 날짜, 출처, 원본 링크, 현재 상태 및 이용 자격 미확인을 보존했다. 공식 16곳은 안양천변 위치이므로 거리 보도의 50m 점검에서 제외한다.

서울 전체에서 공개된 자료를 수집한 것과 실제 벤치를 전수조사한 것은 다르다. 서울 전체 50m 간격 충족은 미달성이다. 데이터 공백을 실제 벤치 부재로 단정하지 않는다. 이름 있는 도심 도로의 25m 간격 표본과 등록 벤치의 50m 직선 근접 점검 결과는 survey-20261029/coverage/에 저장한다. 이 수치는 보행거리·도로 양쪽 연결·50m 최대 간격의 보증이 아니다.

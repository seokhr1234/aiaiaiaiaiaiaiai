- 외부 OSM 배경 타일 요청을 앱과 독립 HTML에서 제거하고 내장 서울 Canvas 배경으로 교체.
- 독립 HTML에 배경 JSON이 내장되어 파일 실행 시 배경 데이터 fetch가 필요하지 않음.
- 브라우저에서 서울 전체 보기를 실행해 내장 도로·구 이름·시설 마커가 함께 나타나는 화면을 확인. '서울 내장 지도 · 인터넷 없이 표시' 안내와 수량 유지 확인.
- 배경 필터링/외부 타일 URL 없음/내장 JSON, 시설 검사, 기존 경로 검사 모두 통과.

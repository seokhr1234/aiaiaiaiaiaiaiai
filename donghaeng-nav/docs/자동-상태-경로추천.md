# 상태 입력 → 자동 경로 추천 · 2026-10-31

## 사용

상위 폴더에서 node server.mjs 실행 후 http://127.0.0.1:4173 접속. 상태를 적고 **내 상태에 맞는 길 찾기**를 한 번 누릅니다. 기본 ON인 자동 AI 해석이 Gemini에 상태 문장만 보내 이동 조건을 읽고, 실제 도로망·지형 경사·휴식 장소 자료로 경로를 계산합니다. 위치·목적지·지도 자료는 Gemini에 보내지 않습니다.

AI 해석만 먼저 볼 수도 있고, 해석된 계단·경사·휴식·거리 조건 및 벤치/쉼터 선호를 수정할 수 있습니다. 같은 상태는 해석을 재사용해 재계산마다 전송하지 않습니다. 새 입력·조건 변경 시 대기 응답을 취소하고, 출발/도착이 바뀐 요청은 이전 조건으로 자동 진행하지 않습니다. 자동 AI 해석을 끄면 기본 문장 규칙을 사용합니다.

제공된 GEMINI_API_KEY가 비어 있어 실제 Google 응답 성공은 미확인입니다. 서버에 키를 설정해야 실제 AI 해석을 사용합니다. 키 없음·시간 초과·오류·HTML 파일 직접 실행 시 기기 내 해석으로 경로 추천을 계속하고 화면에 구별해 표시합니다.

## 경로 정책

- 계단 회피와 휠체어의 등록 계단 제외를 유지합니다.
- OSM 경사 표기를 우선하고, 없는 구간에 공개 지형 표고에서 구한 추정 경사를 반영합니다. 경사·거친 노면·보도 정보 부족에 비용을 부여합니다. 경사 자료가 없는 구간을 평지로 처리하지 않습니다.
- 사용자가 명시한 경사 상한(예: 5%)은 등록값과 지형 추정값 모두에서 초과 구간을 제외합니다. 자료 없는 구간은 별도로 표시하며 상한 충족을 보장하지 않습니다. AI가 임의의 경사 상한 수치를 만들지 않도록 합니다.
- ‘벤치·의자 우선’, ‘쉼터 우선’, ‘함께 찾기’를 실제 경유 후보 선택에 적용합니다. 자동 휴식 후보는 의자 182곳 + 쉼터 48곳입니다. 단지 내부·제한 출입·회원 대상·부지 대표점 등은 자동 경유에서 제외하지만 지도 원본은 보존합니다.
- 쉼터 공식 자료의 기본·연장·추가 요일과 시간을 한국시간으로 해석해 등록 운영시간 밖이면 자동 경유에서 제외합니다. 운영시간 안이어도 계절 지정·현재 개방·이용 자격은 미확인으로 표시합니다.
- 경유점은 실제 도로망에서 접근 가능한지, 시설까지 연결 거리가 35m 이내인지, 추가 우회가 700m 이내인지 확인합니다. 이 연결 자체는 현장 미검증입니다.
- 쉼터를 경유할 수 없고 의자를 대신 고르면 실내·냉방 조건 미충족을 명확히 표시합니다. 휴식 후보 자체가 없으면 휴식 미충족으로 표시합니다. 여러 번의 휴식 간격을 보장하지 않습니다.
- 결과에는 적용 조건, 선택한 휴식 장소, OSM/지형 추정/자료 없음 비율, 추정 최대 경사와 출처를 보여 줍니다. 시설 표시 토글은 계산 조건을 바꾸지 않습니다.

## 지형 자료와 한계

실제 AWS 공개 Mapzen/Tilezen Terrarium 타일 6장으로 기존 월곡역 도로망을 보강했습니다. 17,697개 연결 구간의 추정치를 만들었으며 원본 타일·해시·계산법은 data/terrain/README.md에 있습니다. 보도 경사 실측값은 아니므로 화면에 지형 추정으로 표시합니다. 교량·터널·비지상 도로는 지표 고도를 적용하지 않습니다. OSM 원본과 시설 17,485건은 변경하지 않았습니다.

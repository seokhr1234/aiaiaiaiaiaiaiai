> 최신 경로 선택 수정: [북쪽 우회 원인 분석](docs/북쪽우회-원인분석.md). 미확인 구조물이 최대 경사 비교에서 빠지던 오류를 공통 엔진에서 수정했습니다. 지명·방향 예외는 없습니다.

> 최신 경사 보강: [월곡 전 도로 경사 보강](docs/월곡-전도로-경사보강.md). 21,553구간 분류, 지형 고도 결측 0개, 구조물 별도 확인. 조건 불충족 시 위험 대안을 독립 이동 추천과 구분합니다.

> 휠체어 경사 회피 최신 규칙: [수정 및 실제 도로망 검증](docs/휠체어-경사우회-수정.md). 유효 등록·참고 추정 5% 초과 회피, 미확인 부담 강화, 경로 없음 시 조건 유지. 통행 안전 인증은 아닙니다.

> 경사 자료의 최신 적용 기준: [조사 자료 검토 결과](docs/경사자료-검토결과.md). 서울시·Copernicus 자동 대체 0개, 자료 차이·구조물은 미확인, 기존 참고 추정 규칙은 유지하되 노면 경사·휠체어 통행 가능의 확정 판정으로 쓰지 않습니다. 아래 이전 단계의 경사 상한 설명보다 이 기준을 우선합니다.

# 동행길 · 월곡역 최종 시연본

몸 상태를 문장으로 적으면 월곡역 주변 실제 OpenStreetMap 도로 그래프에서 경로를 계산합니다. 지도·시설 자료를 포함한 HTML은 인터넷과 API 키 없이 실행됩니다. 외부 배포는 하지 않았습니다.

## 바로 실행 · Gemini 통합본 (2026-10-31)

프로젝트 상위 폴더에서 다음을 실행합니다. Node.js 18 이상이 필요하며 별도 패키지 설치는 없습니다.

```sh
node server.mjs
```

http://127.0.0.1:4173 에서 월곡역 최종 HTML과 API를 함께 사용합니다. `동행길-실행.command`를 더블클릭하면 크롬을 엽니다. 키가 없으면 `/setup`의 키 입력칸에 붙여넣고 **저장하고 연결 확인**을 누르세요. 터미널에서는 키를 입력받지 않습니다. Google 인증·모델 조회 결과가 화면에 나오고, 성공하면 같은 서버에 바로 적용되어 길 찾기 화면으로 이동합니다. 키 변경은 `동행길-API설정.command` 또는 `/setup`에서 합니다. 실행 창은 서버이므로 열어 두고, 종료는 Ctrl+C입니다. 개발용 분리 소스 화면은 http://127.0.0.1:4173/app/ 입니다.

`동행길-실행.command`로 실행하고 크롬의 설정 화면에서 Gemini 키를 저장하세요. 키는 로컬 서버에만 보관하고 HTML에 넣지 않습니다. 기본 모델은 실제 생성 응답을 확인한 `gemini-3.5-flash-lite`입니다. 2026-10-31 실제 Gemini 해석과 월곡역→서울사대부중 앞 정류장 경로까지 확인했습니다.

**사용 순서:** 상태 입력 → **내 상태에 맞는 길 찾기** 한 번. 기본으로 AI가 상태를 해석하고 경사·벤치·쉼터를 반영합니다. 조건 체크·휴식 선호 선택·별도 해석 버튼 없이 입력 문장에서 자동으로 판단합니다. 적용된 조건과 추천 이유는 결과에서 읽을 수 있습니다. 상태 문장만 Google에 전송하며 위치·목적지는 보내지 않습니다. 같은 상태의 성공한 AI 해석은 재사용합니다. 실패하면 기기 내 문장 규칙으로 전환됐음을 표시하고, 다음 길 찾기에서 AI를 재시도합니다.

**고도 보강:** 월곡역 실제 공개 지형 타일을 도로 좌표에 결합했습니다. OSM 경사 표기와 지형 추정을 구별하고, 사용자가 명시한 경사 상한과 벤치·쉼터 선호를 반영합니다. 지형 추정은 보도 실측이 아닙니다. 자세한 계산·검증은 `docs/자동-상태-경로추천.md`와 `data/terrain/README.md`를 확인하세요.

서버 없이 `동행길-최종.html`을 최신 Chrome에서 직접 열면 지도·시설·규칙 기반 길 찾기를 계속 사용할 수 있습니다. 이 모드는 AI 서버 미연결과 기기 내 해석 사용을 명시합니다. `동행길-시연.html`도 같은 내용입니다.

‘30초 비교 시연’과 발표 모드는 이전과 같습니다. 실제 현장 GPS는 기기 권한·수신 상태를 확인하고, GPS가 없으면 ‘월곡역으로’로 시연 기준점을 복원하세요. 외부 배포는 하지 않았습니다.

## 동작과 데이터의 의미

- 월곡역 시연 기준점 → 월곡꿈그림도서관이 기본 경로입니다. 현재 GPS 위치와는 구별해 표시합니다. 지도에서 핀을 옮기거나 목적지를 검색할 수 있습니다.
- 서버 실행 시 Gemini가 상태 문장에서 계단·경사·휴식·거리 조건을 자동으로 추출합니다. 연결 실패·파일 단독 실행 시 한국어 문장 규칙을 사용했음을 표시합니다. Gemini는 경로·시설·좌표를 생성하지 않습니다.
- 등록 계단 제외, 경사·노면·도로 속성 가중치, 휴식 지점 경유를 실제 도로 그래프에 적용합니다. 단지 내부·출입 제한·부지 대표점·정밀도 불명 벤치 추정점은 자동 휴식 후보에서 제외합니다.
- 시설 표시 ON/OFF는 경로 조건과 독립적입니다. 시설 검색·출처 팝업·현재 화면 내 수량을 유지합니다. 팝업에서 월곡역 도로망 안의 장소를 목적지로 선택할 수 있습니다.
- 지도 번호와 이동 순서를 연결하며, 단계별 강조·시뮬레이션·GPS 근접 확인·브라우저 경로 저장·제보 저장을 제공합니다.
- 도로와 출발/도착점의 미검증 연결, 휴식 지점 왕복 연결을 거리·시간 추정에 포함합니다. 휴식 시간 자체는 포함하지 않습니다.
- 서울 전역 시설 자료와 월곡역 주변 길 찾기 범위는 다릅니다. ‘기록 수’는 실제 의자 개수나 전수조사 결과가 아닙니다. 단지 경계와 제보 구역도 개별 벤치로 세지 않습니다.
- 시설은 현장 미확인입니다. 과거 사진·공식 설치 기록·부지 기준 좌표를 구별하며 실시간 운영 여부, 경사·턱·폭·출입구와 휠체어 통행 가능을 보장하지 않습니다.
- 지도와 길 찾기는 네트워크 없이 동작합니다. 원본 근거 링크를 여는 동작에는 인터넷이 필요합니다. GPS는 서버로 보내지 않습니다. 길 찾기를 누르면 상태 문장만 서버를 거쳐 Google로 전송하며, 경로·제보 저장은 이 브라우저에만 적용됩니다.

## 시설 지도 레이어 (2026-10-28)

현재 기능의 소스는 `donghaeng-nav/dist/`이며, 상위 폴더의 `dist/`는 이전 시안으로 유지했습니다. `scripts/build-html.py`는 기능·시설 데이터·내장 벡터 지도를 합쳐 상위 폴더의 `동행길-시연.html`을 갱신합니다. 외부 배포는 하지 않았습니다.

- 벤치: 기본 ON, 초록색 의자 아이콘. 계단: 기본 OFF, 주황색 계단 아이콘과 실제 선형. 에스컬레이터: 기본 OFF, 보라색 아이콘과 실제 선형.
- 지도 왼쪽의 ‘시설 지도’에서 종류별 표시와 전체 켜기/끄기. 모바일은 기본 접힘이며 터치 버튼은 44px 이상입니다.
- ‘⌖’로 종류별 전체 범위를 볼 수 있습니다. 전체 수와 지도 경계 안의 수는 표시 ON/OFF와 별도로 집계합니다. 선형은 꼭짓점이 화면 밖이어도 화면을 통과하면 포함합니다.
- 가까운 벤치는 숫자가 있는 묶음으로 표시합니다. 누르면 확대되며, 최대 확대에서도 겹치면 개별 의자와 원본 위치 연결선으로 펼칩니다. 팝업에는 원본 좌표를 표시합니다.
